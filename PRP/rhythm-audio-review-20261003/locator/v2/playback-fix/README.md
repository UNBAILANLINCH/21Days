## 最小操作

- **从头播放完整40秒**：退出局部/自定循环，从片段0开始播放到40停止（原曲16–56s）。任何时候都能直接点。
- **退出循环 / 回到完整片段**：停止并恢复完整0–40s范围，关闭循环，播放头回0，等待用户再播放。时间轴旁的“完整片段 / 退出循环”也有此行为。
- **循环试听此音符**：选中音符前后声音，进入明确的“音符附近”模式并播放。范围状态文字显示当前ID、片段/原曲起止、是否循环与播放/暂停状态。
- **停止并回到范围起点**：停止播放，回当前模式的起点；播放/暂停保留位置。启动AudioContext时显示“正在启动音频”，再次点播放/暂停或停止可以取消未完成启动，避免重复预约。
- **自定区间**：在“播放范围”选自定，再设起止和循环。播完非循环区间会停止。拖动播放头到局部区间外，会回完整模式寻址，不再被暗中夹回旧区间。
- 音符附近模式中换note，会更新范围并暂停，不自动骚扰播放；完整模式换note不会缩小播放范围。A/B不重置区间或候选。最后音符范围最多到40，无选择note时仍能完整播放。
- **整首原音频试听**：页底独立原生audio控件可听约163秒原曲；它与40秒游戏谱面分开，开始原曲试听会暂停谱面试听，完整40秒按钮会暂停原曲，避免混音。不扩展谱面范围。

范围/暂停/退出操作只改播放状态，不清空候选、草稿或当前页撤销记录。草稿、严格审核导出及旧v1候选兼容与v2保持一致。
