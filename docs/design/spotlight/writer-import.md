## 玩法接线边界

剧情阶段图保留20个稳定等待节点：14个明确登记的地点衔接、6个源稿玩法或演出环节。这是阶段图边界数量，不等于玩家需要完成20个操作；地点字段变化不再自动生成任务。同一说书梦境内的地点切换连续播放。

这些等待点使用既有 `WaitAction`。正常入口只加载SampleScene，人界为Z+300地图；李诏阳交谈后由70交互进入24血切磋教学，再到83寻找戏台旁赵十四。129书库连续叙事，无独立跑点；171入镜只传到妖界平台，不提交剧情。玩家须到左桥后轮回堂值守E才播放21008，再到二三层楼梯下端的坊市光点188按E查看酒肆二楼窗边何素、播放21009。妖界保留原坐标及五店，293以后的调查机制仍待实现。

关卡接线使用 `NarrativeService`：有效登记目标调用StartAsync，实际等待完成才以ResultIntent／SubmitAsync提交Success，不直接改存档。129在人界自动衔接；入镜成功不能提交171（它在妖界代表实际轮回堂问询）。稳定目标在同场景共用，避免两界复制ID。等待点与源行号见对照文件waits。

正式任务900现为四项实际结果：三店、酒肆BOSS、21010、21011，会面后完成，没有永久阶段二占位。原HUD／列表保留，当前目标按剧情覆盖为交谈／入镜／轮回堂／坊市，197恢复真实三店目标。Quest存档v3兼容旧七项序号及已抵达本段终点的旧档；正式配置只启用900，保留其它旧任务数据。八处后续调查／奖励未全部制作，本批文本结束不代表全游戏结案。最新实测及未验项见change-review最新章节。

## 更新方式与自检

使用带 `openpyxl` 的 Python 运行 `scripts/import-writer-story.py <工作簿路径>`，输出补丁供 `apply_patch` 审阅和应用；不会直接修改工作簿或生成物。之后运行 `scripts/gen-tables.ps1`，刷新 Unity，并运行 DialogueCatalogTests 和 NarrativeCatalogTests。

转换器自检：`python scripts/import-writer-story.py --self-test`。连续“文书”行合并并用换行保留全文，非文书仍逐行输出；自检同时检查文字完整性与后续跳转。未知选项和未拥有的对白编号冲突会拒绝导入。更新后需检查旧对白是否已不再被阶段引用，再明确处理废弃源文件，不自动删除其它内容。
