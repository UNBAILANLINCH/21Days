# 共用探索小地图

2026-10-13 用户授权实现，并明确：小地图是主界面的一部分，常驻左上角、任务栏上方，供探索场景共用。
需求源：`docs/design/spotlight/04_美术需求表.md` 的「场景地图/导航缩略图」。

## 范围与决定

- 进入探索自动显示小地图；保持玩家操作与世界推进，不持暂停令牌、不接管按键。
- 用实际场景活跃网格的 XZ 包围盒绘制等比示意图，标当前位置、可加载出口和已有楼梯。
- 同一个 Hud 层控件随当前玩家场景更新；沉浸时跟随共用 HUD 隐藏，标题或没有玩家时隐藏内容。
- 小地图放在左上角，任务栏移到下方；不改世界移动、传送、存档和内容表。
- 不新增地图模块或依赖，实现在既有 World 内。
- 暂不做正式美术底图、楼层筛选、任务标记、寻路、迷雾与敌人扫描。

## 资产与扩展限制

`Assets/_Project/Prefabs/UI/SceneMapView.prefab`，UI 组地址 `SceneMapView`。
地图由 `WorldInstaller` 注册，正式 Boot 流程可用。
`SceneMapBuilder` 生成该界面并调整 `QuestHudView.prefab` 的任务栏位置，不改场景；通过 Unity 菜单 `21Days/世界/生成最小场景地图` 执行。
`build-menu.json` 是现有 `scripts/unity_mcp_invoke.py execute_menu_item --args-file` 的菜单参数。
正式美术接管后停止重建，以免覆盖人工布局。

轮廓是轴对齐矩形，不是精确地形或导航网格；重叠楼层暂叠画。
楼梯按 Stair／楼梯命名识别；两张世界灰盒尚无楼梯几何，不虚构标记。
出口可见表示目标场景已实装可加载，不代表剧情通行条件已满足。
