## 首版组合（设计推导）

用户查看旧结算截图后指出过程文字太多，对“轮流出”的暂定倾向是界面分步。首版据此采用“选出指→猜总数→看结果”，玩法仍同时猜数，每步只显示当前六项；允许回到出指重选。结算优先只显示“你喝一杯／对方喝一杯／平局”，原出拳过程与新消息收进展开详情，有新消息时入口明确提示。保留真实消息，不用删除线索来减字。

采用对称折角浅板与顶端菱结标题，主操作在中心、动作固定底部；与任务的倾斜列表、背包网格和金银行阵盘分别组织，不复制其业务构图。

复用Confirm空白纸板、金银行无字主标题底、背包格子／选中格与云形动作钮。动态“行酒令”、对手、醉意、数字、酒令与结果全部TMP；不生成带文字整图，不新增位图或字体。宋体Bold／黑体Regular与近似边界沿风格参考。

| 部件 | 实际绑定／设计参数 |
| --- | --- |
| Paper | `Confirm/ui_confirm_panel.png`，1520×932，近似保持778:477比例；根遮罩RGBA(.035,.09,.1,.7)；板与标题底Image白色tint，保留PNG alpha |
| TitleFrame／Heading | `Forging/Delivery20261020/主标题底.png`，455×94；可编辑宋体Bold50、`#216A79`，不使用烘焙“金银行”的标题图 |
| 对手／醉意 | 原Title／Status；宋体Bold34／24，`#216A79`／`#5C95A1`，数据继续由原接线传入 |
| FingerRoot／CallRoot | 两组互斥，每组六项140×140、间距180；复用背包cell两态，黑体Regular34；手柄左右选项、向下固定到当前主要动作，持久选择和导航焦点分开 |
| Result | 宋体Bold46，必要时缩到34；同一阅读区域显示当前操作提示或一行结论；一处CanvasGroup／子Canvas隔离短时alpha |
| Details | 宋体Bold27、最低22，1120×250；默认收起，保留原双方出指／喊数／合计和真实消息；新消息按钮明确提示 |
| 动作 | 原Confirm／Next／Back名字与事件保留；新增ChooseCall／ChangeFinger／DetailsButton只管表现。云形两态＋UITextButton＋UIButtonFeedback，普通深青字、聚焦深底浅青字；按钮文字34，详情入口24 |

`TavernFingerGuessBuilder` 发现Paper后拒绝白盒覆盖；修正原defaultSelected赋GameObject而非Selectable的问题。保留其Node／Label接口，`SpotlightStoryBuilder`调用不受影响。旧白盒无分步字段时仍可按原接口显示；现有正式预制体已接齐全部分步字段。没有修改ShopPlaytestState、规则、学习、配置或Addressables地址。

## 恰好三版动效方案

| 方案 | 触发、动线、时序 | 交互、中断、暂停与成本 |
| --- | --- | --- |
| A 席间递读（推荐） | 根面板沿原150ms Fade；出指与合法喊数即时变化，结果沿下方阅读区160ms OutQuad淡入；结果留至玩家再来／离席，关闭原150ms | 悬停／导航沿UGUI，按压80ms至0.94恢复；结果重复先取消旧淡入，隐藏／关闭／销毁复原，unscaled；只一处局部alpha，无布局逐帧刷新 |
| B 举杯回稳（仅文字） | 根仍150ms，结果区180ms从0.98回1，结论延迟40ms；选择即时，无强制等待 | 聚焦提亮、按压80ms；中断取消归位，暂停unscaled，退出原Fade；多一个短缩放，不持续弹跳 |
| C 酒令展开（仅文字） | 首开标题280ms显现，出指／喊数依次隔60ms，总500ms内；揭晓仍即时，结果文字220ms淡入 | 导航不等待演出，可直接终值；隐藏／销毁停止还原，unscaled；额外分组alpha，禁止逐字拖慢真实结算 |

选择A：操作频繁、游戏世界已暂停，反馈应清楚并即时可用；B／C不建立运行时切换框架。时长为设计值，性能未实测。
