# 戏班扩展

换谱须同步RhythmInstaller的单曲config与TheaterConfig.Chart；固定策略比较song/chart/revision/ruleset/scoring五项身份。新增岗位或路线需明确场景引用并补前置和过期权限测试。

改规则后跑本模块EditMode；改场景、界面或回店流程后跑本模块Showcase。场景和预制体用Unity编辑器保存，不手写YAML/meta。不得运行时修改SO。

仍为现有四轨下落式，主场景占位已用学徒/都知/乐正称呼；光点形式、正式人物美术、身份道具与主线过关效果未接。调整路线应保持角色生命/控制归属，并同步保存前置与路线恢复。
