# Tap 新增 / 删除试听工具

入口 **http://127.0.0.1:8769**。服务窗口保持打开；需要启动时双击本目录 `launch.cmd`。使用项目现有 MP3、canonical SO 与已有 Node，无需安装依赖。8768 等旧服务和用户页面保留；本目录独立提供页面，复用既有只读源解析与 v1 校验器。

## 操作

- 选轨后点“当前播放头新增”，或填写整数毫秒后点指定时间新增。仅允许 Tap，落点为片段 `[0,40000)` 毫秒，对应原曲 `[16,56)` 秒。
- 明确开启“点击四轨新增模式”后，点击波形下方的四轨添加；关闭后恢复原有选择、寻址和拖动。没有全局新增/删除热键，输入框打字不触发编辑。
- 选音符后删除，确认框展示 ID/轨道/时间。撤销/重做保留生成的 UUID 和选中项；原 `legacy-*` ID 不重排。只修改候选，不修改原谱或音频。
- A/B、音符片段循环、从头播完整 40 秒、退出循环、节拍/音符 click、自由拖动/参考吸附沿用原工具。新增音符在 A 中没有对应音符；试听区域以候选音符位置定位。
- 草稿允许声部/理由留空，显式保存到浏览器或下载 JSON。严格候选导出必须选择“旋律”或“伴奏”并填写理由，仍标记 `unapproved-candidate`，不代表贴拍正确。

## 迁移与格式

**保留旧 8768 标签页，不刷新、不关闭。** 在旧页应用待输入时间，下载草稿 JSON；在新 8769 页导入、核对差异，再保存。端口不同，浏览器本地草稿不会自动迁移。JSON 不迁移旧页内存撤销历史。

工具 envelope 版本为 **2**，正式 SO 的 `chart.schemaVersion` 仍是 **2**，服务健康版本为 3。支持严格验证后导入 v1 草稿/候选，保留来源 hash、审核声部/理由及未批准状态；旧工具不支持含新增/删除的 v2 导出。新增 ID 为 `review-UUIDv4`；差异明确为 `add/remove/move`，不存在的前/后时间使用 `null`。原有音符的 lane/type/duration 不可改，允许时间移动和删除；不支持新增 Hold。

导入/导出校验原谱和音频路径、SHA-256、时间域、版本/状态、ID 唯一性、整数新增时间、边界、同轨判定窗口与 Hold 占用、完整差异清单；来源变化时拒绝保存/导出。候选音符数量可变，没有固定 56 条假设。空候选也可保存，不能误认成可玩正式谱面。文件只用于人工审核和手工导入；本工具没有写回或自动应用接口。

## 输出限制

时间域是项目 MP3 解码结果：片段 0–40s = 原曲 16–56s，未添加解码器补偿。WebAudio 以 AudioContext 同时预约歌曲与 click，循环 click 使用同采样率 buffer；浏览器、操作系统、设备输出延迟和 MP3 解码差异仍存在，画面/听感不构成声学同步精度证明。BPM、拍号原点只是用户参考；工具不做自动 onset 判定，不自动决定跟旋律还是伴奏。隐藏/失焦时停止工具播放。

