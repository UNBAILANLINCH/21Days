# 演出（Performance）

> 状态：可用（示例演出为占位立绘）　·　是否已接进游戏：已挂 Boot　·　程序文档：[三件套](../../ai-docs/docs/modules/performance/performance-module-guide.md)

## 1. 一句话

演出是插在探索或对话里的一小段「表演」：一个角色出场做几秒到十几秒的动作，配字幕和停顿点，播完自动回到原来在做的事；一段演出默认只播一次。

## 2. 玩家看到什么、做什么

- 走进场景里某片区域，或对话说到某一句时，画面上下压出黑边，一个角色走进画面表演（现在的示例用的是老者的占位立绘，正式角色以后会换成 Live2D 模型），底部依次出现字幕。
- 字幕是逐字打出来的（和对话一样），打字过程中点一下画面会把当前这句直接补全显示，不会跳到下一句；演出里出现「▼ 点击或按空格继续」提示时（字幕打完才会出现），鼠标点一下画面，或按确认键（空格 / 回车 / 手柄 A，和对话的推进键一样）才会继续（没停顿、字也打完时点画面不会有反应，也不会跳过）；不想看时按住跳过键（左 Ctrl / 手柄 RB，和对话的跳过键一样）约 1 秒直接结束这段演出。
- 播完（或跳过）后黑边收起，世界恢复：如果这段演出是走进区域触发的，玩家可以继续走动；如果是对话中插播的，对话框重新出现，接着说下一句。
- 演出进行期间，原来的探索 HUD、任务栏、对话框都会先隐藏，播完按进来之前的状态恢复（如果进来之前它本来就是藏着的，比如对话里插播演出，播完也不会把它擅自亮出来）。
- 同一段演出只播一次，播完（不管是正常播完还是跳过）都会记住，再次走进同一片区域或再次触发不会重播。
- 演出期间 Esc 不会把它关掉，和对话一样。

## 3. 规则

- 同一时刻只能有一段演出在播，重复拉起会直接抛错（和对话服务同样的规则）；场景触发区在演出正播放时进入不会再触发一次。
- 每段演出有四个独立开关（挂在演出预制体上）：**是否可跳过**、**是否暂停世界**（`timeScale = 0`）、**是否隐藏 HUD**（连带隐藏对话框所在的弹窗层）、**是否上下黑边**；默认四个都开。
- 跳过：长按跳过键满配置的秒数（默认 1 秒）直接结束，结果记「已跳过」；自然播完记「已完成」；两种结果都会写进「已播过」列表，一次性演出不会因为跳过而下次继续弹出。
- 停顿点（▼）：时间轴走到「等待输入」标记就自动暂停，必须按确认键才会继续，不会自己过去。
- 三种挂载方式：**场景触发区**（走进去播，可设「只播一次」）、**场景加载即播**、**对话某一句之前插播**；任何模块的代码也能直接按编号拉起一段演出。
- 对话插播：演出播放期间对话框隐藏、不推进、不收玩家输入（和对话本身「被遮挡」时的状态一样）；演出结束后对话自动接着显示下一句台词。
- 演出播放期间不存档；中途关游戏重进会当成没播过，从头再播一次（一次性演出如果之前已经完整播过或跳过过，则仍然不会再播）。

## 4. 策划 / 动画师能改什么

**每段演出（在演出预制体上）：**

| 想改什么 | 在哪改 | 字段 | 改了影响什么 | 备注 |
| --- | --- | --- | --- | --- |
| 是否可长按跳过 | 演出预制体根上的 `PerformanceStage` 组件 | Skippable | 关掉后玩家长按无效，只能等自然播完或按确认走完每个停顿点 | 默认开 |
| 演出期间是否暂停世界 | 同上 | Pause World | 关掉后角色仍能走动，画面不冻结（其余开关各自独立） | 默认开 |
| 演出期间是否隐藏 HUD / 对话框 | 同上 | Hide Hud | 关掉后 HUD 层与弹窗层（含对话框）不隐藏 | 默认开 |
| 是否上下黑边 | 同上 | Letterbox | 关掉不压黑边 | 默认开 |
| 谁出场、说什么字幕、什么时候停顿、配什么动作与音效 | 打开演出编辑器（见第 8 节）里的时间轴，编排字幕 / 表情 / 动作 / 音效四条轨 | — | 决定这段演出具体演什么 | 改完点「校验」 |

| 挂载方式 | 在哪配 | 字段 | 备注 |

- 示例演出 `perf_sample_greeting`：3 条字幕、1 个停顿点，时长约 8 秒，时间轴带一段入场位移动画，演员是占位立绘（老者）。
- 对话 `1003`（验证用）：老者、旅人各说一句，第二句台词「老先生，我就看一眼——」之前插播 `perf_sample_greeting`。
- 世界舞台示例 `perf_sample_scene_talk`：五个方舟小人（阿米娅、德克萨斯、能天使、陈、斯卡蒂）站在 `SampleScene` 村口的灰盒场景里对话，6 句字幕、不压黑边，舞台相机接管整个画面（近景微俯）。由菜单 `21Days/演出/生成示例·场景对白（世界舞台）` 生成（`Editor/Performance/Samples/SceneTalkSampleBuilder.cs`，可重复执行、原地覆盖），挂在 `SampleScene` 的村口触发区 `Trigger_VillageEntrance` 上，走进去触发。是目前唯一的**世界舞台模式**示例，8.6 节的参照就是它。
- 回放在 `Assets/Scenes/SampleScene.unity` 上跑，一套回放用例覆盖：代码直接拉起演出、长按跳过提前结束、走进触发区自动播且只播一次、对话中插播并在演出结束后接着说下一句。
- 演出编辑器菜单 `21Days/演出/演出编辑器`：能列出全部已登记的演出、一键创建、打开时间轴、校验、Play 模式下试播。

## 6. 已知限制与还没做的

- **Live2D SDK 与模型未导入**：现在只能用占位立绘（`SpritePerformanceActor`）做演员；SDK 导入、编译符号自动加上（`Live2DDefineSync`）、以及 `Live2DPerformanceActor` 的实际表现，都待 SDK 导入后核实。
- **没有相机运镜预设**：构图靠时间轴自带的位移 / 缩放动画自己摆，没有镜头语言的现成模板。
- **不做配音与口型**：设计支柱明确不做配音（roadmap D3 备注）。
- **演出中不能存档**：也不支持中途暂停后从中途恢复，中途退出重进会从头再播一次。
- **触屏专属操作延后**：跳过 / 确认现在只有键鼠 / 手柄路径，触屏按钮延后到移动端移植阶段（PC 优先）。
- **演出内不能插分支选项、不能多段并行、不能在演出里嵌一段对话**，这些明确不在本期范围内。

## 7. 和其他模块的关系

- 被 [对话](dialogue.md) 调用：对话树节点的 `performance` 字段可以在某一句台词之前插播一段演出；插播时对话框隐藏，演出结束后对话继续显示下一句。
- 依赖 Core 服务：世界暂停（演出期间冻结世界）、UI（面板全屏显示黑边与字幕，整层隐藏 HUD / 对话框）、资源（按 Addressables 地址实例化演出预制体）、存档（记住哪些一次性演出已经播过）、输入（复用对话的确认 / 跳过按键，没有单独的按键图）。
- 依赖 Unity 官方 Timeline 包编排字幕 / 表情 / 动作 / 音效四条轨道。
- 依赖 URP 相机栈：播放时把舞台相机叠加到主相机上，因此与 [探索表现](isometricexploration.md) 共用同一个主相机与渲染管线分档。

## 8. 给动画师：怎么做一段演出

### 8.1 新建与打开

1. 打开菜单 **`21Days/演出/演出编辑器`**。
2. 在工具栏「新建演出…」旁边的输入框填一个 id（小写字母 / 数字 / 下划线，如 `perf_intro`），点后面那个按钮——它的文字是**「创建」**（不是「新建」），会一步建好预制体、时间轴、图层和 Addressables 登记。
3. 新建后你拿到的是：**四条空轨道**（字幕 / 表情 / 动作 / 音效）；时间轴是**固定时长模式**，默认 **8 秒**；预制体里已经有一个占位演员（物体名 `Actor`，挂了 `SpriteRenderer` + `SpritePerformanceActor` + `Animator`），表情轨、动作轨已经绑好这个演员——但它的**表情列表是空的**，要先在它的 Inspector 里填几条「名字 → Sprite」，表情轨才有名字可选（见 8.3）。
4. 点「打开时间轴」，Unity 的 Timeline 窗口会显示这四条轨道，以及一条放「等待玩家确认」停顿标记的标记轨。拖时间线就能实时看到效果（拖动预览不会触发停顿标记，见 8.2）。

### 8.2 逐轨怎么摆

**字幕轨**：轨道空白处右键新建一个字幕片段，填两项——**说话者**（留空 = 旁白，面板隐藏名字栏）、**正文**。片段本身的起止时间就是这句字幕在画面上显示的区间。**容易踩的坑：字幕是硬切换，不支持混合也不做淡入淡出**，两句衔接就是这句消失、下句出现，想要间隔就在片段之间留空。正文没写会标红：「这条字幕还没写正文。」片段上会自动显示「说话者：正文前 12 字」方便你认哪句是哪句。

**表情轨**：先在 Timeline 窗口里把演员（占位演员或 Live2D 演员）拖进轨道左侧的绑定槽，再新建表情片段，填**表情名**——必须和演员表情列表里的名字**一字不差**（大小写敏感）。**容易踩的坑：片段开始的一刻切一次表情，片段结束不会自动回退**，两句字幕之间的空白会保持上一个表情，想换回来要再放一个片段指定原表情。轨道没绑演员时片段会标红：「表情轨道没有绑定演员。」表情名对不上会标红：「演员『X』没有表情『Y』。」（校验窗口里的对应文案见 8.4。）

**动作轨**：普通 Unity `AnimationTrack`，没有本模块自定义的语义，直接把动画片段（`AnimationClip`）拖进去即可，绑定对象是演员身上的 `Animator`（模板已经绑好占位演员的）。**Live2D 模型的动作**是模型导入后由 Cubism 工具生成的动画片段（`.motion3.json` 会变成 `AnimationClip`），做法和精灵演员一样，直接拖进「动作」轨，不需要额外转换。

**音效轨**：普通 Unity `AudioTrack`，拖入音频片段（`AudioClip`），按 Unity Timeline 通行规则播放，没有自定义行为。

**停顿标记**：在最上面的标记轨里对应时间点新建一个 `HoldMarker`，可以填一句备注（`label`）——这句话**只给你自己看，不会显示给玩家**。时间轴走到这个点会自动暂停，必须玩家按确认键（点击画面 / 空格 / 回车 / 手柄 A）才会继续，不会自己走过去；**只在真正播放时触发一次，拖时间线预览不会误触发**，你可以放心拖着看效果。**容易踩的坑：停顿标记不能放在 0 秒处或总时长处（含边界）**，放错了会标红：「停顿标记放在了时间轴开头或末尾之外，玩家可能等不到它。」标记旁边会画一个「▼」提示。

**总时长**：新建演出默认是固定时长模式（Fixed Length），默认 8 秒，在 Timeline 窗口顶部可以直接改数字。总时长是 0 秒会被校验拦下：「时间轴总时长是 0 秒，播出来一闪就结束。」

**可以直接抄的节奏**（来自世界舞台示例 `perf_sample_scene_talk`）：每句字幕片段 **4 秒**，句与句之间间隔 **0.3 秒**，停顿标记放在每句片段**结束前 0.1 秒**（必须落在片段内部，▼ 才会跟着字幕一起出现，不会卡在空白期），总时长 = 最后一句结束时间 **再加 0.5 秒**留尾。

### 8.3 舞台上要填的

- **演员名单（`PerformanceStage` 组件的 `cast`）**：每条是「说话者 → 头像 → 站位」。说话者要跟字幕片段里的「说话者」字段**一字不差**（大小写敏感）才会显示头像，对不上不报错，只是这句不带头像（校验器给 Info 提示）；同一个说话者填了两条，**只有第一条生效**；说话者留空的那一条永远匹配不上任何字幕。这三种情况校验都会标黄。站位（左 / 右）按这个说话者在舞台上的实际站位配——站在画面左边的角色配左，站右边的配右，决定该角色说话时头像出现在对白面板左侧还是右侧头像位。
- **换掉占位演员的图与表情列表**：模板新建的 `Actor` 物体上，`SpritePerformanceActor` 的表情列表（`expressions`）默认是空的——在 Inspector 里逐条填「名字 → Sprite」，这些名字就是表情轨里能填的表情名（大小写敏感）。填完列表不会自动显示任何一张——想在摆位时看到人，把第一张图也拖进同物体 `SpriteRenderer` 的 Sprite 槽。
- **演员必须在 `Performance` 图层**：叠加模式下校验器会逐个检查舞台下的物体是不是在这个层（不在会标红「不在 Performance 图层上，舞台相机拍不到它」）；世界模式不检查这条（演员就站在世界里，不限图层）。用演出编辑器新建时整棵树已经设好了，只有你后来自己往舞台里加物体才需要手动补一下图层。
- **`PlayableDirector` 必须和 `PerformanceStage` 挂在同一个物体（舞台根）上，不能拆开**：停顿标记的通知、字幕轨道找字幕面板输出端，都是发给「Director 所在物体上的 `PerformanceStage`」，拆开了这两样都会失灵（且不会报编译错误，只会运行时不动）。

### 8.4 校验对照表

点「校验」会按 Error（红）/ Warning（黄）/ Info（提示）分级列出问题，文案抄的都是校验器原文。

**Error（必须改，否则播出来一定不对）**

| 提示文案 | 意思 | 你怎么修 |
| --- | --- | --- |
| 「X」根物体上没有 PerformanceStage 组件，它不是一段演出。 | 校验的这个物体压根不是一段演出的预制体 | 确认选中的是演出预制体；正常用演出编辑器新建不会出这个问题 |
| 根物体上没有 PlayableDirector，时间轴没地方播。 | 舞台根缺 `PlayableDirector` 组件 | 补一个 `PlayableDirector`（模板新建的都带着，一般不会缺） |
| PlayableDirector 没有挂时间轴资产（Playable 一栏是空的或不是 Timeline）。 | Director 的 Playable 栏没接时间轴 | 把对应的 `.playable` 资产拖进 Director 的 Playable 字段 |
| 时间轴总时长是 0 秒，播出来一闪就结束。 | 见 8.2「总时长」 | 把 Timeline 窗口顶部的总时长改成大于 0 |
| PerformanceStage 的舞台相机（Stage Camera）没接，演出画面出不来。 | 两种模式都要接 Stage Camera 槽 | 把舞台相机物体拖进 `PerformanceStage` 的 Stage Camera 槽 |
| 表情轨「X」没有绑定演员（轨道左侧的绑定槽是空的），表情不会切换。 | 见 8.2「表情轨」 | 把演员拖进表情轨左侧的绑定槽 |
| 表情轨「X」在 Y 秒处要切「Z」，但演员「W」没有这个表情。 | 见 8.3 | 去演员的表情列表里补上这个名字（大小写要一致），或把片段里的表情名改成列表里已有的 |
| Addressables 里没有把这个预制体登记成地址「X」，游戏里按这个 id 播不出来。 | 地址没登记 | 正常新建都会自动登记；手动挪过预制体或改过地址的话，去 Addressables Groups 窗口把地址改回和 id 一致 |

**Warning（可能不对，需要你看一眼）**

| 提示文案 | 意思 | 你怎么修 |
| --- | --- | --- |
| 舞台相机不是 URP Overlay（Render Type 应为 Overlay），会盖掉游戏画面。（仅叠加模式查） | 舞台相机类型不对 | 把舞台相机的 Render Type 改成 Overlay |
| 舞台相机的剔除遮罩（Culling Mask）除了 Performance 还勾了别的层，会把游戏场景再画一遍。（仅叠加模式查） | 剔除遮罩多勾了层 | 把 Culling Mask 里除 Performance 外的层都取消勾选 |
| 世界模式的舞台相机应为 URP Base（Render Type 改成 Base）：它要接管整个画面，而不是叠在主相机上。（仅世界模式查） | 相机类型不对 | Render Type 改成 Base |
| 世界模式的舞台相机应为透视相机（Projection 改成 Perspective），否则看不出纵深。（仅世界模式查） | 相机是正交的 | Projection 改成 Perspective |
| 舞台相机打了 MainCamera 标签：演出期间 Camera.main 可能取到它，服务就找不到真正的主相机。（仅世界模式查） | 舞台相机误打了标签 | 把舞台相机的 Tag 改回 Untagged |
| 演员名单第 N 条没填说话者，这一条永远匹配不上字幕。 | 见 8.3 | 补上说话者名字，或删掉这条空行 |
| 演员名单里「X」出现了不止一次，只有第一条生效。 | 见 8.3 | 删掉多余的重复行，只留一条 |
| 演员名单里「X」没拖头像，对白面板不会显示头像。 | 见 8.3 | 把对应角色的头像 Sprite 拖进这一条的 Avatar 槽 |
| 工程里还没有名为 Performance 的图层（Project Settings → Tags and Layers），舞台相机没法只拍演出物体。 | 图层被删了 | 去 Project Settings → Tags and Layers 补回名为 Performance 的层 |
| 「X」不在 Performance 图层上，舞台相机拍不到它（或主相机会拍到它）。（仅叠加模式查） | 见 8.3 | 把这个物体的 Layer 改成 Performance |
| 字幕轨「X」在 Y 秒处的字幕片段没有写正文。 | 见 8.2「字幕轨」 | 把这条字幕片段的正文填上 |
| 停顿标记在 X 秒，落在时间轴开头或末尾之外（总长 Y 秒），玩家可能等不到或刚开场就卡住。 | 见 8.2「停顿标记」 | 把停顿标记拖到 0 秒与总时长之间 |

**Info（提示，不影响状态灯）**

| 提示文案 | 意思 | 你怎么修 |
| --- | --- | --- |
| 字幕轨「X」在 Y 秒处的说话者「Z」不在演员名单里，这句不会显示头像。 | 见 8.3；旁白（说话者留空）不受这条影响 | 这句确实要显示头像的话，去演员名单里补一条同名的说话者 |

### 8.5 试播与挂载

1. 编好后点「校验」，参照上面的对照表把问题改到没有红项（Error）为止；黄字和提示建议看一眼，不强制改。
2. 从 Boot 场景进 Play（点标题「开始」进入游戏），回到演出编辑器窗口点「试播」，能在游戏里实际看一遍这段演出的效果。
3. 挂到游戏里怎么触发，见第 4 节「挂载点」表：场景触发区、场景加载即播、对话某一句之前插播三选一。

### 8.6 世界舞台模式

前面几节说的都是**叠加模式**（默认）：舞台是叠在游戏画面上的一块独立小舞台，跟世界位置无关。**世界舞台模式**（`PerformanceStageMode.World`）是另一种：演员直接站在 3D 场景里说话，舞台相机接管整个画面，不压黑边——适合「玩家在探索场景里，几个角色围在原地对话」这种场面，对标明日方舟活动探索地图的对话演出。**没有通用模板**：模板工厂 `PerformanceTemplateFactory` 只产叠加模式的空壳，世界模式要照抄示例 `perf_sample_scene_talk`（见第 5 节）自己改内容，没有「新建」按钮直接给。

和叠加模式的四点差别：

| 项 | 叠加模式 | 世界模式 |
| --- | --- | --- |
| 舞台相机 | 正交、URP Overlay，只拍 Performance 层，叠在主相机画面上 | 透视、URP Base，接管整个画面（渲染主相机能看到的一切 + Performance 层） |
| 主相机 | 不受影响 | 演出期间保持存在（`Camera.main` 不能变空），但不再实际渲染场景，结束后恢复 |
| 摆放锚点 | 忽略摆放，舞台内容跟世界位置无关 | 演出实例会被摆到调用方给的世界位姿上（比如触发器的锚点物体） |
| 演员图层 | 必须在 Performance 图层 | 不限图层，演员就是站在世界里的物体 |

场景侧的触发器（`PerformanceTrigger`）要多填三项：**`anchor`**（一个世界锚点物体，决定演出实例摆到哪个位置、朝哪个方向）、**`hideActorVisual`**（演出期间是否把玩家自己——包括头顶名牌——藏起来）、**`hiddenDuringPlay`**（演出期间要一起藏起来的场景物体，比如和舞台上同一个形象的 NPC、还在场景里走动的巡逻怪、会飘在画面里的头顶标记）。

程序侧的实现细节见[开发手册 6.16 节](../developer-guide.md)与[模块指南「世界模式」一节](../../ai-docs/docs/modules/performance/performance-module-guide.md)。
