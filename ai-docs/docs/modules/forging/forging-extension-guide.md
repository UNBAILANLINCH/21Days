# 打造扩展

改成本、额度、提交数量和点击顺序用Forging.asset。四点位索引只能0至3。更复杂打造先明确输入、成功/失败/取消和材料承诺，再换该规则；不把UI点击直接接为Loot发物。

改规则后跑本模块EditMode；改场景、界面或回店流程后跑本模块Showcase。场景和预制体用Unity编辑器保存，不手写YAML/meta。不得运行时修改SO。

替换背景、圆盘或按钮直接编辑ForgingView预制体，保留序列化的三个工件按钮、三个数量文字、四个点位按钮及主要控制按钮引用；Addressables地址保持类名。ABC目前是物品名称占位，正式名字到位时替换界面标签并确认正式物品/事实ID，不自行推定剧情用途。增加第四类工件须同步规则、配置、快照和旧存档迁移，不能只加UI按钮；界面新增操作须经现场许可委托进入Controller。

复用ItemCraftRules只做材料可用判定。本地金属/A/B/C编号1/2/3/4只在规则内部，不是正式物品表ID。未完成工件只预留材料，取消释放预留；已完成材料不退。调目标数量时保持总成本不溢出，超过库存上限的订单通过补料完成；不得把24重新当作累计预算。
