# 实施任务与验收对应

1. 登记两个模块、写 seed guide、冻结首版需求与数值。覆盖验收 1–6 的书面依据。
2. 扩展 Gameplay 动作与输入快照映射，建立 Player 纯规则、运行数据、配置及输入测试。覆盖验收 4–6。
3. 建 Monster 感知、状态、巡逻、战斗规则和测试。覆盖验收 1–5。
4. 将 Player/Monster 固定顺序接入 SimulationRunner 与回放状态注册；验证快照往返和版本拒绝。覆盖验收 1–6。
5. 用 Unity 编辑器建遭遇场景、占位表现、触屏控件、Boot 接线、Addressables 与两个验证场景。覆盖验收 1–6。
6. 编写并运行两个 Showcase，确认控制台、lint、资产体检和可见反馈；同步模块三件套与目录。覆盖验收 1–6。
