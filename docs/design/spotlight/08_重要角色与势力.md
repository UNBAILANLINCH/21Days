## 1崔皓

### 1.1 基础信息

| 项目 | 内容 |
| --- | --- |
| 姓名/旧称 | 崔皓。宫中旧人称他“崔方相”；流落民间后，街坊叫他“崔师傅” |
| 别名/职名 | 摆渡人；“镜主” |
| 性别/年龄 | 男/四十上下。要有年龄感，略有些颓废苍凉，身形算比较魁梧 |
| 身份职业 | 宫廷傩戏神官出身，流落民间；在彩云班落脚，靠唱戏与教人吃饭；现任摆渡人之一，执锁魂镜 |
| 所属势力 | 摆渡人 |
| 外貌标记 | 举镜时永远侧着，因为他知道这个镜子里映照不出自己 |
| 第二外貌标记 | 腰间挂着一个极旧的黄金四目方相面具，黄金色黯淡，毛皮快被磨秃 |
| 声音/说话习惯 | 声音沙哑，语速较快，说话短而简练，偶尔杂以唱腔 |
| 随身物件 | 镜，师刀，方相面具，妻子的耳环 |
| 是否可操作/战斗 | 主操作角色。对抗通过追逐/躲藏/弱点识破/场景利用/战斗四件套实现 |
