# 视觉验收清单（只有人能做的那一步）

> **状态：待验收（2026-10-07 建立）**
> **为什么有这份**：`docs/module-dev-spec.md` 第 2 节 DoD 第 4 条写着「`/verify-module` PASS，**且开发者看过回放并点头**」，并明确「**自动化能证明数值对、没报错，证明不了看起来对**；AI 不做视觉验收」。当前工程里有一大批**代码完成、测试全绿、但从未被人看过**的功能，它们全都卡在同一个动作上：**有人坐在 Game 视图前看一遍**。
> **怎么用**：每项跑一条命令（或按「怎么看」那一列操作），在「结论」列填 `过 / 不过 / 待看`，不过的写一句现象。填完这份就是本阶段的验收记录。
> **本文只列**「机器已经绿了、只差人眼」**的项**；还在失败或没实现的项（如 Narrative 战斗结果）不在本文里。

## 0·一次跑完所有回放

回放报告落在 `Logs/verify/<模块小写>/<时间戳>/report.md`（已 gitignore）。每个模块一条命令：

```
/verify-module <模块名>
```

**注意**：回放会占着共用编辑器，**一次只跑一个模块**；`/verify-module` 的 PlayMode 调用过 `guard.js` 的 run_tests 分支，一次验多个模块要逐条列、每条只匹配一个模块（`.claude/rules/model-routing.md` 硬规则 6）。
