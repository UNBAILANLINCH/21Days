# PRD: 任务系统（主线 / 支线 · 追踪 · 指引）

> 日期：2026-09-25。前置：对话系统（[`PRP/dialogue-system/`](../dialogue-system/prd.md)）已落地并接进 SampleScene（三个 NPC、交互拉起对话、对话结束事件）。
> 本 PRD 覆盖「任务从配置到指引」的完整闭环：任务表 → 激活 / 推进 / 完成 → HUD 任务栏 → 任务面板 → 追踪 → 地图指引 → 存档。奖励、失败、限时、通知弹窗留后续。
> 参考表现：明日方舟探索模式（用户给的两张截图：左上任务栏「找到落脚处 / ★ 观察神秘生物」；画面下缘「! 11m ▾」距离方向标）。

## 问题 / 动机

玩法未定的阶段，探索场景里已经有 NPC 与对话，但玩家进场后没有任何「该去做什么」的指引，验证玩法也无法串成一条线。任务系统要解决三件事：

1. 策划不写代码就能用配置串出一条主线和若干支线，指定每一步要玩家做什么。
2. 玩家随时知道现在追踪的是什么、下一步去哪，画面上有方向和距离指引。
3. 任务进度可持久化，其它模块（对话、探索、后续战斗）通过统一入口上报进度，不各自维护任务状态。

## 目标（可度量）

- G1 **全走配置**：新增或修改任务只改配置表并重新生成，不改任何代码；配置里写明任务是主线还是支线。
- G2 **HUD 任务栏**：游戏内左侧常驻任务栏，显示当前追踪任务的标题与当前目标；追踪变化或目标进度变化后 1 帧内刷新。
- G3 **任务面板**：点任务栏打开面板，列出全部已接取的任务；当前主线恒定在列表最上方，支线按接取先后依次排列；选中一项可看完整详情（标题、类型、描述、全部目标及完成状态）。
- G4 **追踪 / 取消**：详情下方一个按钮，未追踪时为「追踪」，已追踪时为「取消追踪」；同一时刻最多追踪一个任务。
- G5 **地图指引**：有追踪任务且当前目标有指引地点时，画面上有指向该地点的标识并显示距离（整数米）；目标在画面内时标识悬浮在目标上方，在画面外时贴画面边缘并带方向箭头；无追踪、目标无地点或目标不在当前场景时不显示。
- G6 **进度持久化**：任务状态、每个目标的进度、当前追踪的任务写进存档分区；存档后读回与存档前一致。

## 范围 / 非目标

- 做：任务配置表（Luban）与内容校验；任务规则（激活 / 推进 / 完成 / 排序 / 追踪）纯逻辑与 EditMode 测试；与对话模块联动（对话结束推进「与某人对话」目标）；场景任务点（到达触发）；其它模块上报进度的统一入口；HUD 任务栏、任务面板、指引标识三个表现件；存档分区；SampleScene 示例任务（一条主线 + 一条支线）；验证场景与 Showcase；模块文档三件套。
- 不做：任务奖励（道具 / 货币 / 经验）、任务失败与限时、任务放弃、任务接取 / 完成的弹窗通知（只对外发事件，表现留后续）、已完成任务列表页、任务对话（对话内容仍归对话表）、小地图、多语言、联机。

## 玩家故事 / 关键场景

- 作为玩家，我进入探索场景，左上角任务栏告诉我「找到落脚处 / 观察神秘生物」，画面下缘有个「! 11m ▾」提示目标在下方 11 米。
- 作为玩家，我朝指示方向走，目标进入画面后标识悬浮在目标上方；走到地点后目标打勾，任务栏切到下一个目标。
- 作为玩家，我和 NPC 对完话，任务栏里「与平台主人叙个旧」自动完成，主线推进到下一个任务。
- 作为玩家，我点任务栏打开任务面板，第一行永远是当前主线，下面是我接的支线；点一条看详情，点「追踪」后任务栏和指引都切到它。
- 作为玩家，我再点一次「取消追踪」，任务栏变成「未追踪任务」，指引消失；再打开面板还能重新选。
- 作为玩家，我追踪的支线做完了，任务栏自动回到当前主线，不用我再手动点。
- 作为玩家，我存档退出再进来，任务进度和追踪状态都在。
- 作为策划，我在任务表里加一行「支线：观察三只神秘生物，前置：找到落脚处，目标：到达地点 A（指引到场景里的 A 点）」，重新生成配置，进游戏就能玩到。
- 作为开发者，我在场景里放一个带地点编号的任务点，配置里引用这个编号，玩家走进去目标就完成；我的模块要上报「观察了一只生物」，调一个统一入口就行。

## 配置需要表达什么

每条任务：唯一编号、类型（主线 / 支线）、标题、描述、前置任务（可多条，全部完成才激活）、有序的目标列表。
每个目标：显示文本、完成条件类型、条件参数、需要的次数（默认 1）、指引地点（可空）。
一期支持的完成条件类型：

| 类型 | 参数 | 何时完成 |
| --- | --- | --- |
| 与某人对话 | 对话编号 | 该编号的对话正常结束（被跳过也算） |
| 到达地点 | 场景地点编号 | 玩家进入该地点范围 |
| 计数 / 标记 | 自定义键 | 其它模块通过统一入口上报该键，累计达到需要的次数 |

「与某人对话」的指引地点可以留空，由系统指向该对话所属的 NPC。

## 任务生命周期与规则

- 任务状态：未激活 → 进行中 → 已完成。前置任务全部完成的任务自动激活；没有前置的任务在首次进入游戏时激活。
- 主线是一条链：同一时刻最多一个进行中的主线；上一个完成后下一个自动激活。支线可多个同时进行。
- 目标顺序推进：任务的「当前目标」是第一个未完成的目标；只有当前目标接收进度，后面的目标不提前累计。全部目标完成即任务完成。
- 追踪：默认追踪当前主线；玩家可改追踪任一进行中的任务或取消追踪；被追踪的任务完成后自动切回当前主线（没有主线则不追踪）；取消追踪后不追踪任何任务。
- 任务面板打开时世界暂停（与对话共用同一套暂停机制），关闭后恢复。对话进行中任务栏与指引隐藏，对话结束恢复。

## 验收标准

- [ ] A1 规则：前置全部完成即激活；主线同一时刻最多一个进行中；当前目标累计到需要次数即完成并推进；全部目标完成即任务完成；非当前目标不接收进度（EditMode）。
- [ ] A2 排序：面板列表当前主线恒定第一；支线按接取顺序；没有主线时列表从支线开始（EditMode）。
- [ ] A3 追踪：默认追踪当前主线；追踪 / 取消追踪切换正确；追踪的任务完成后回到当前主线；没有主线时不追踪；同一时刻最多一个（EditMode）。
- [ ] A4 内容：真实生成的任务表通过校验：编号唯一、类型合法、前置引用存在且无环、每个目标有文本与合法条件类型、「与某人对话」引用的对话编号存在于对话表、「到达地点」必须有地点编号（EditMode 内容检查）。
- [ ] A5 存档：任务进度分区写入后读回，状态 / 每目标进度 / 追踪编号一致；旧存档缺分区时按「全新开始」处理（EditMode）。
- [ ] A6 指引数学：给定相机、玩家与目标位置，目标在画面内时标识落在目标投影点上方；在画面外时贴边缘、箭头指向目标；距离为玩家到目标的整数米（EditMode 纯函数）。
- [ ] A7 联动：对话结束后，对应「与某人对话」目标完成；玩家进入任务点后，对应「到达地点」目标完成；通过统一入口上报的计数正确累计（Showcase 检查点）。
- [ ] A8 表现：Showcase 回放能看到：任务栏显示追踪任务的标题与当前目标；点任务栏打开面板；列表主线置顶；详情按钮在「追踪 / 取消追踪」之间切换；指引标识随目标进入 / 离开画面在「悬浮」与「贴边」之间切换并显示距离；取消追踪后任务栏占位、指引消失；支线完成后追踪回到主线（开发者看回放点头）。
- [ ] A9 面板打开期间世界暂停、Gameplay 输入图关闭；关闭后恢复（Showcase 检查点）。

## 涉及模块 / 依赖

- 新建 `Assets/_Project/Scripts/Runtime/Quest/`（`Game.Quest`）：任务规则、内容适配、进度上报入口、场景任务点与场景扫描、三个表现件、存档分区、注册器。
- `Game.Dialogue`（只读复用，不改）：订阅对话结束事件推进目标；从可交互组件取 NPC 位置做指引；对话进行中隐藏任务栏与指引。
- `Game.Narrative`：本期不动。任务完成写入剧情标记留后续（对话选项条件仍走剧情标记）。
- `Game.Core`：UI 服务（Hud 层任务栏与指引、Panel 层任务面板）、存档服务（新增任务分区）、配置服务（新表自动纳入）、世界暂停服务（面板打开时复用）、事件（任务激活 / 目标进度 / 任务完成 / 追踪变更四个已发生事实事件）。
- `Tables/`：新增任务表（Luban；任务→目标为嵌套结构，输入格式在 PRP 阶段定）。
- 新资产：`Prefabs/UI/` 下任务栏、任务面板、指引标识预制体；`Data/Quest/` 配置资产；`Scenes/Verify/Quest.unity`；Boot 场景挂任务注册器；SampleScene 放任务点标记与示例任务（主线：与某 NPC 对话；支线：到达某地点）。
- 第三方：无新增包。

## 待确认问题（已按默认决定推进，可事后调整）

- Q1 任务内的目标是顺序推进还是可并行？默认**顺序**（HUD 只显示一个当前目标，与截图一致）；要并行只需目标加「组号」，规则层小改。
- Q2 支线怎么接取？默认与主线一样**靠前置任务自动激活**（前置为空则开局激活）；「通过对话接取」留后续，由对话结果调统一入口激活。
- Q3 取消追踪后任务栏是隐藏还是占位？默认**占位文本「未追踪任务」**，保留点开面板的入口。
- Q4 已完成的任务要不要在面板里看到？默认**本期不显示**，存档保留完成记录用于前置判断。
- Q5 指引距离怎么算？默认玩家到目标的**直线距离（世界单位按米取整）**，不做寻路距离。
- Q6 面板要不要绑键盘 / 手柄动作？默认**只点任务栏**（触控与鼠标），后续需要再在 UI 动作图加一条。
- Q7 对话「被跳过」算不算完成「与某人对话」目标？默认**算**（跳过是玩家主动行为，对话仍走到结束）。
