2. 主页「阶段一玩法设计」写音乐解谜改为点击圆圈光点、不另开音游界面；04 的 UI 分页仍有「BOSS血条（与音游界面叠加）」「结算界面（分数、最大COMBO、评价）」。
3. 两份大纲阶段一不同（见 01 附节）。
4. 主页「讨论记录 · 参考（游戏/美术/背景参考）唐朝历史」下的图（讨论记录_参考图.jpg）画面是一张像素风游戏截图叠加红/橙扇形，看起来像潜行视野范围的参考，与「唐朝历史」字样未必对应。
5. 02 酒肆写「详见回合制作战文档」——该文档原先不在飞书本页、仓库里也没有，**2026-10-07 由策划补交并入库为 07**，问题已消。
