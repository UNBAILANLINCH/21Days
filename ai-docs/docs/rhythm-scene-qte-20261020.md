## 场景与重建入口

`RhythmDemo.unity` 的独立 RhythmInstaller 指向新配置、开启 qtePilot、不加载曲库。`ConfigureQtePilot` 仍复制配置，只增加接纳本次新曲；其他未知 chartId 仍拒绝。原曲和新曲通过统一只读 `Title` 显示标题，不按 MP3 英文文件名猜标题。

编辑器入口：`21Days/音游/应用场景QTE与锅碗瓢盆`。首次从归档谱面建立配置；已有配置不覆盖手工拍点。场景已有 `QteInnBackdrop` 时保留其编辑；八角部件沿原 `ApplyQtePromptArt` 接线。

独立 Demo 的 `QteInnBackdrop` 复用 SampleScene 妖界客栈附近可见网格和材质，使用既有客栈舞台构图以及 Chibi_player、Chibi_yuezheng 表现预制体。这里只建立局部可视舞台，没有复制 NPC、任务、店铺、碰撞或另一套世界控制逻辑，也没有修改 SampleScene 的剧情接线。正式世界中的 QTE 面板同样可透明叠加；本批没有将所有正式旧玩法入口改为新曲。

## 三版动效方案

| 方案 | 触发、时间与焦点 | 重复／中断／暂停与成本 |
| --- | --- | --- |
| A 稳定浮现（采用） | 当前/下一组即刻在受控位置出现，键字不平移或弹跳；下一组 0.4 透明度晋升为 1。外圈按既有绝对音乐时刻收拢，到圈重合按键；结算键字关闭，键帽／圈原位退场 180ms。没有悬停，按键反馈沿用中文短句。 | 重试重置，关闭隐藏；暂停冻结音乐时刻与淡出。位置按组计算，文本只按事件更新；不叠新动画框架。 |
| B 轻浮入场（未实现） | 键帽在 100ms 从目标下方 4px 归位并淡入，字同时出现，EaseOutQuad；停留和收圈同 A，结算 180ms。 | 重复取消旧入场并归位，暂停冻结，关闭复位；需短时位置更新，快速敲击时会增加读键负担。无悬停。 |
| C 呼应演奏（未实现） | 场景人物先给演奏动作，键帽延后 40ms 用 100ms 淡入；收圈仍严格沿音乐时刻，字不缩放，结算 180ms。 | 重复／关闭取消并复位，暂停同步动作；需要可靠演奏动作素材及动作接线，本批不凭空制作。无悬停。 |

保留现有高频节拍的稳定读键，采用 A；没有实现三套切换器。文字样式、原键帽 hash 与 Regular 模拟加粗的差异沿用[前批记录](rhythm-qte-art-20261020.md)。
