# 正式对话 UI 素材

2026-10-13 接入用户提供的对话框、头像框、选项按键与继续三角形；源 PNG 原样保存，透明通道不改。

- `Yang/`：阳间素材，当前默认使用。
- `Yin/`：阴间素材，仅准备样式；**不按妖界场景自动切换，不擅自绑定剧情节点**。
- `ui_dialogue_continue.png`：半透明白色继续三角形。

继续三角形按用户参考放在面板右下、装饰左侧。`HoldPrompt` 右下锚点、位置 (-252,11)；在 1920×1080 下三角形中心为 (1585,62)，左下为原点；提示文字随其显隐。

Unity Sprite 裁切（左下原点）：矩形底框 `(209,35,1606,265)`、独立石鸟 `(1545,31,366,396)`；头像框 `(63,98,347,348)`，排除源图右侧红色参考块；三角形 `(1556,66,51,24)`。矩形裁切也排除源图上方残留的红点。选项图原尺寸 576×107，九切边距左/下/右/上 54/24/54/24。UI 导入关闭 mipmap 和压缩。旧合成面板 PNG 保留作来源参考，运行时已使用拆件。

对白与演出共用 `DialogueView.prefab` / `PerformanceView.prefab` 的正式样式，原地址不变。头像人物图仍用既有资源，左右说话者的显示规则不变。`UIPanelAppearance` 在画布渲染前读取已接线头像的实际显隐；名字跟随可见头像靠左/靠右，独立 `StoneBird` 和矩形底图放在头像对侧并镜像。继续标和提示布局随侧别切换，文字和人物图自身保持正常方向。入退场重叠时跟随透明度较高的一侧；不读取场景或剧情状态。

文字使用 `Art/Fonts/SourceHanSerifCN/SourceHanSerifCN-Bold.otf` 生成的动态 TMP SDF（2048 图集，允许多图集），不再叠加伪粗体。正文与选项目标字号 34.06；超长选项可缩至 24，角色名 44.45 白色，键位提示 22。阳间正文/选项 `#1B174F`；阴间采用 TMP 顶部白色、底部 `#670A0A` 的顶点渐变，SDF Glow 底色 `#520B0B`。

截图没有给出外发光的精确半径、强度；当前为效果近似（GlowOuter 0.12、GlowPower 0.5）。阴间文字材质在 `Art/Materials/ui_text_serif_yin.mat`，可在 Inspector 调整。

两份面板根上的 `Game.Core.UI.UIPanelAppearance.Apply(bool)` 只提供显式切图预览入口，没有场景监听、剧情状态判断或运行时调用方。后续剧情节点确定时由剧情流程决定何时切换；若节点中途已有选项实例，接入时须一并刷新已生成的选项。

字体只导入实际使用的 Bold 字重，并保留字体内版权声明及 SIL OFL 1.1 许可证。
