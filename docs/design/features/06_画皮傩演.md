## 1·一句话

把收押过的妖的面皮制成傩面具戴上，暂借它的记忆与本事去接近、查案、有限地正面对抗；代价是妖的念头会渗进主角的念头。

## 3·规则

**获取**

- R1 面具的来源＝先用镜识别身份，再收押该妖，再取其附身动物 / 人的面皮制成傩面具；三步缺一不可。[原文]（`2_世界观圣经.md §2 门 2`；`3_角色与势力档案.md §1.5`）
- R2 面具里的妖没有死，仍在皮里。[原文]（`2_世界观圣经.md 铁律 3`）
- R3 面具认主，不可继承、不可转手。[原文]（`2_世界观圣经.md §4`）由此推出：崔昭的旧皮面具不能交给主角用。[推断]
- R3a 没有收押过“附身于动物 / 人”的妖，就拿不到面具；只照见不收押不给面具。[推断]（由 R1 三步推出）

**效果**

- R4 佩戴时暂得该妖的记忆与本事，并演绎其身份。[原文]（`2_世界观圣经.md 铁律 3`；`1_核心 §5`）
- R5 画皮的首要产出是信息（记忆、可接近的对象、可查的线索），战斗能力是次要产出。[原文]（`1_核心 §3·支柱 3`：“重点仍然是让玩家获取信息”；`3_角色 §1.5`：“去查案”）
- R6 同一时间只能佩戴一张；每次进入相关战斗只能携带一张。[原文]（`2_世界观圣经.md §2 门 2`）
- R7 主角不戴面具时不能与妖正面冲突；戴面具时可进行“特定”精英战 / boss 战的有限正面战斗。[原文]（`2_世界观圣经.md 铁律 1`、`§2 门 2`；`1_核心 §3·反面清单`）哪些战斗算“特定”由关卡逐个指定。[推断]

**代价**

- R8 面具有生效时间与冷却，不能长期佩戴。[原文]（`2_世界观圣经.md 铁律 3`、`§2 门 2`；`3_角色 §1.5`）时限以“时辰”计的叙事口径可参考崔昭“数皮剩下的时辰”。[推断]（`3_角色 §2.5`）
- R9 用妖的力量＝让妖住进脑子里；佩戴过久会分不清哪些念头是自己的。[原文]（`2_世界观圣经.md 铁律 3`；`3_角色 §1.5`）第一章表现为“龙的念头会污染主角”。[原文]（`story 第一章 C5`）
- R10 佩戴期间的叙事视角要体现“身不由己”。[原文]（`2_世界观圣经.md 铁律 3`·玩家如何感知）
- R10a 污染量与佩戴时长正相关（“佩戴过久”）。[推断] 是否有阈值、是否跨场景累积 [待定]，见 Q5。

**退出**

- R11 佩戴者自愿归还，妖可离皮；归还后该面具随之消失。[原文]前半（`2_世界观圣经.md 铁律 3`·例外）；“面具消失”[推断]。
- R12 戴与不戴都能推进剧情：不戴要付出额外调查（多绕一趟取物证），换取视角干净。[原文]（`story 第一章 C5`）

## 8·设计约束与检验问题

- 面具不许做成纯战斗装备：每张面具必须能回答“戴上它，玩家多知道了什么”。（支柱 3）
- 正面战只在“特定”精英 / boss 战开放；普通遭遇不因戴面具变成正面战。（反面清单第一条、铁律 1）
- 不许无代价：时限、冷却、污染至少有一项必须被玩家感知。（铁律 3；世界观禁区“不出现无代价的辨认手段”的同一精神 [推断]）
- 不做数值成长：面具不升级、不叠属性。（支柱 1“放弃了数值成长”；`3_角色 §1.4`）
- 不许同时佩戴多张，不许长期佩戴。（门 2）
- 不许强引导“该不该戴”：C5 两边都要有理由。（支柱 2 检验问题 [推断] 适用）
- **检验问题（支柱 3）**：玩家做完这个动作，获得了什么信息？答不出，就重写奖励。

## 9·待定与开放问题

1. Q1 面具库存上限：可同时持有几张？“做不到同时佩戴多个”只限佩戴，没限持有。
2. Q2 切换时机：能否在遭遇中途换面具？门 2 只说“每次进入相关战斗只能携带一个”。
3. Q3 生效时间与冷却的具体数值、计时单位（现实秒 / 游戏内时辰 / 场景次数）。
4. Q4 冷却与剩余时限是否跨场景、跨存档保留。
5. Q5 污染的表现形式（台词、选项、画面、档案）与是否持久；是否影响结局可用性。
6. Q6 “记忆”以什么形式交给玩家：对白、镜中档案条目、视角切换演出，还是三者组合。
7. Q7 **原文缺口**：`story §1.4` 把“面具的代价”列为二幕 L1 规则，但二幕 B1–B14 没有交代它的场次，而第一次戴皮在三幕 C5。代价在何处、由谁告诉玩家？

9. Q9 **原文矛盾**：`story §4.3` 写收押敬元颖的立即后果是“面具＋账簿”；D2 正文写收押后她“作为助手（更容易看破伪装）”，未提面具。且门 2 写面皮取自“附身动物 / 人之面皮”，而敬元颖是镜精，取什么皮？

11. Q11 被识破：戴面具时，谁能识破（同族妖？被模仿者的熟人？镜精助手？），识破后是强制摘下、进入追逐，还是记账？
