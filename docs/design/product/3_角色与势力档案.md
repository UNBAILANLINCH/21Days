# 0·镜

镜不会拒绝任何人，在做出决定和选择之前，它会回答“**这是什么**”——也就是关于真形的答案。

镜陪人到岔路口，人向前走去的时候，镜就留在原地。

规则是人定的，镜有“答问”和“处置”的两个权能。

#### 1.4 人物成长弧光设计

起始：依赖他人，认为找到父亲就能解决问题得出答案，因此他的目的和决定受他人影响较大。

转折：第二章中，被依赖者的离开；第三章中，父亲之死和“仪式真相”，迫使他开始思考自己的选择，并开始试图回答自己的问题。

终止：终章中承担责任，选择做出自己的选择。

成长弧线：正向成长，但无“变强”环节，没有数值上的提升。

验证：序章和终章对镜的态度和使用，在终章时他没有再照镜子，而是将镜子翻转了过去。

## 2·反派

### 崔昭

反派，影子主角 首次出场|序章 正式登场|第二章 退场|终章

一句话定位：一个同样不知道自己是谁的人，一个觉得选择能决定一切的人，不择手段地证明自己的价值。

核心：他的偏执与他的爱是同一个动作。

他想证明自己的弟弟和自己没有区别，从而证明自己的资格。陷入偏执的他一边要把崔映变成自己，一边不能让崔映真的变成自己——弟弟越早把事定死，他越早得到证明；可弟弟真碎了，他就什么也不剩了。他需要一个完好的人替他活着，好让他知道自己当年本来能成为什么。

所以他的行为永远是：不留痕迹而严丝合缝地推动主角行动，在最危险的时刻伸出援手。每一次都这样。

他在每一个单元都会强调自己扮演的角色。他是那个知道自己在扮演什么，选择了自己要走什么路，但是仍然处于迷茫中的人——换句话说，不坚定。

#### 3.3 与崔昭

崔昭十一岁那年，求崔皓用镜把母亲带回人间——而崔皓自己就是为这件事被困在镜里的。崔皓知道三件事：

1. “把人带回人间”是律条不许的事——他自己正在做，他没有资格骂这个孩子；

2. 一个十一岁的孩子抱着这种念头去碰镜，会把自己也处于危险的境地；

3. 他拦不住。

于是他下了一道判定：「崔昭不算崔家的人。此后不许近镜。」

| 说给谁听 | 意思 |
| --- | --- |
| 对两界 | 他已经不是摆渡人家的人，出事和账别记到他身上 |
| 对崔昭 | 别碰那面镜子——碰了，你就再没有回头路 |
| 对他自己 | 他把自己也推出了那个家：从这天起，他不再是一个“能劝儿子”的人 |

他为什么不解释：解释就要承认两件事——①我是为了护你才不要你的；②我替你决定了一次你的人生。所以他宁可让崔昭恨他。

写作纪律：这一段不许写成"父亲是为他好"。要让玩家自己推出来，并且同时看见两种读法——"他在保护"与"他在抛弃"——两种都成立，直到第三章的那一瞬。

#### 3.4 人物弧光

起始（宫中）：他相信傩能驱疫、官身能护住规矩，因此他戴上面具，按规矩办事。

转折（和崔昭争吵）：他亲手把孩子推出了门。他成了他最不想成为的那种人：用规矩断人情的人。最终他选择了去试着把何素带回来。

终止（1 年前）：他触犯法则，被困死在镜中，不入轮回；留给两个孩子的是一面镜、一把师刀、一瞬间。

成长弧线：幻灭。

## 4·母亲

### 何素

主要配角（最长陪伴者）｜首次出场 序章（主角跟随她行动）｜身份揭示 终章前

一句话定位：一个知道全部答案、却一个字都不能说的人——她陪着孩子，却不敢相认。

核心：她是这桩案子里唯一能"开口作证"的人，而她不能说。

崔皓被困在镜中；崔昭不知道她的身份；主角不知道自己是谁。

全篇唯一知道全部真相的人，是一个永远站在门槛外的人。她不是不敢说——她一开口，她就不再是“那个陪他的人”，而变成“当年把他留下的人”。

#### 4.3何素与崔昭

| 问题 | 答案 |
| --- | --- |
| 她什么时候见过他？ | 他小时候；以及这三年的暗中往来（她给他的那对玉环耳坠，他戴到现在，一半给了崔映） |
| 她为什么找他？ | 因为只有他在查"怎么把人带回人间"。她进不去镜，也求不动任何人——只能借他 |
| 她给了他什么？ | "他父亲那三年在做什么"的线索。这些线索全部为真——她只是没有告诉他她是谁 |
| 他知道吗？ | 不知道。他只记得"有个女人抱过他"，他把这当成小时候的梦 |
| 她为什么不认？ | 认了，他就知道自己是"被留下的那个"；认了，她就要面对"你为什么留下我"，而这个问题她答不出来 |

#### 4.4 人物弧光

起始（序章）：她相信不认就是对这两个孩子的保护，因此她站在门槛外，陪了十六年。

转折（终章前）：崔昭摊牌、主角开始怀疑。这迫使她面对“她这三年到底是在保护谁”的问题。

终止（终章）：她变成那个终于跨过门槛的人。

成长弧线：平弧——她自己不变，改变的是主角。她用三年的"不说"，把身份这个问题一次次推回给玩家。

#### 4.5 说话方式

| 项目 | 内容 |
| --- | --- |
| 句式 | 温、慢；永远不用反问句 |
| 习惯 | 在门槛外说话；不说“我”以外的人称指代自己以外的人 |
| 生气 | 反而更温、更慢，句尾开始脱掉人称 |
| 绝不会说 | “我是你娘”；“你像你爹”；任何一句反问；“阿昭”——她全篇不敢叫这个名字：一旦提到，崔昭就会知道真相。 |
