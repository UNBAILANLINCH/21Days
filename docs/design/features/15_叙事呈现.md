## 1·一句话

故事用对白框＋立绘讲日常，用全屏演出与卷轴插图讲关键时刻，不配音，靠画面和动作而不是台词说出主题。

## 2·玩家看到什么

| 场合 | 看到什么 | 依据 |
| --- | --- | --- |
| 日常对话 | 对白框＋立绘（7 种表情差分） | 1_核心 §1、3_角色 §1.9 [原文] |
| 关键规则落地 | 镜头停在镜面，镜里只有背后的屋子，无字幕 | story P2 [原文] |
| 零台词角色 | 一串动作：看、走半步、停、指、回头等 | story P3 [原文] |
| 本相 / 大场面 | 全屏演出（候选：B8 龙现本相） | [推断] |
| 幕末 / 章末 | 卷轴插图（D12 镜背刻痕特写） | story D12 [原文] |

对应 1_核心 §5「佩戴面具、演绎其身份」一行心理：「我现在说的这句话，是我的，还是它的？」[原文]——R5 的呈现要让玩家产生这个疑问。

## 3·规则

- **R1** 叙事视角为「第一人称 / 第三人称限定」 [原文]（1_核心 §1 表）。两者何时切换、以谁为限定对象 [待定]
- **R2** 三种呈现层：对白框＋立绘；全屏演出；卷轴插图 [原文]（1_核心 §1 表）
- **R3** 不做配音 [原文]（1_核心 §3 反面清单）
- **R4** 主题不在台词里直接说出，由行为落地 [原文]（1_核心 §6 写作纪律）。呈现层要能只用动作 / 镜头讲完一个关键节点 [推断]
- **R5** 戴面具时叙事视角要体现「身不由己」 [原文]（2_世界观 铁律3）；C5 戴皮时「龙的念头会污染主角」、不戴则「视角干净」 [原文]（story §二 C5）。呈现层需要一种可开关的「被污染的视角」状态 [推断]，具体手段（文本插入、画面滤镜、选项被改写等）[待定]；与 [06_画皮傩演](06_画皮傩演.md) 的接口
- **R6** 规则落地时刻用静止镜头＋无字幕 [原文]（story §二 P2）
- **R7** 需要「镜头推近」「镜头停留」这类镜头语言 [原文]（story §二 P2、D10）；B8 龙现本相为全屏演出候选 [推断]
- **R8** 主角立绘：7 种情绪差分（平静 / 专注 / 被问住 / 强撑 / 动摇 / 认命 / 决意，参考美术组产能）；特殊版：照镜版（镜面反光在脸上，反光里没有人）、回忆版（13 岁）、结局版 3 张 [原文]（3_角色 §1.9）
- **R9** CG 清单：序章镜中空白 1、第三章 1、三结局各 1，共 5 张 [原文]（3_角色 §1.9）
- **R10** 选项呈现纪律：关键选择无音效、无高亮、无「重要选择」标记，与普通选项同形 [原文]（story §二 A3）
- **R11** 何素全程零台词，以动作序列呈现；始终站门槛外、隔七八步 [原文]（story §1.5、§二 P3、P5；3_角色 §4.1）。第一章之后是否仍零台词 [待定]（3_角色 §4.5 写了她的说话方式，暗示后续有台词 [推断]）
- **R12** 何素全篇不被叫名字 [原文]（3_角色 §4.1）。因此对白名牌、历史记录、档案等所有界面文本都不应出现「何素」二字 [推断]；她在界面上显示为何 [待定]
- **R13** 崔昭会「换嗓」，对主角永远用本音 [原文]（3_角色 §2.1；story P4「用另一个人的嗓子」）。不配音前提下，换嗓在对白框里如何表现 [待定]
- **R14** 四名主要角色各有「说话方式」表（句式、习惯、情绪、绝不会说），这是文案纪律，对白系统不需要为此加功能；但内容校验器可以查「绝不会说」的词 [推断]（依据 3_角色 §1.6、§2.5、§3.5、§4.5 [原文]）
- **R15** 镜界呈现：西市镜界层中「活人只剩轮廓」；镜中档案是镜界里的一个界面场景 [原文]（story §二 A4、§1.3）。实界 / 镜界需两套场景 [原文]（story §1.3）
- **R16** 失败页面只有「镜碎」两字，不使用「读档」字样 [原文]（1_核心 §5）；细则见 [03](03_镜之耐久与镜碎.md)
- **R17** 章末用卷轴插图收束（D12 镜背刻痕特写，三行） [原文]（story §二 D12）；D10 镜背第三行显示玩家整章写下的判断 [原文]，文本如何由选择生成 [待定]（与 [11](11_分支与结局.md) 的接口）

## 8·设计约束与检验问题

- 不做配音 [原文]（1_核心 §3 反面清单）
- 不做强引导——选项不加提示（R10）[原文]
- 世界观禁区：避免现代科学相关设定，借坊市、宵禁、傩仪、坊墙的文化气质 [原文]（2_世界观 §1）——界面与演出风格同受约束 [推断]
- 写作纪律：不要在台词里把主题直接说出来 [原文]（1_核心 §6）
- 检验问题：这一句台词、这一个场景，是否让玩家多知道一点「谁是谁」？答不出就砍。（支柱1）
