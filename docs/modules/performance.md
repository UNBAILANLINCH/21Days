# 演出（Performance）

> 状态：可用（示例演出为世界舞台 `perf_sample_scene_talk`）　·　是否已接进游戏：已挂 Boot　·　程序文档：[三件套](../../ai-docs/docs/modules/performance/performance-module-guide.md)

## 1. 一句话

演出是插在探索或对话里的一小段「表演」：几个角色（序列帧小人）站在场景里说几秒到十几秒的话，配字幕和停顿点，播完自动回到原来在做的事；一段演出默认只播一次。

## 2. 玩家看到什么、做什么

- 走进场景里某片区域，或对话说到某一句时，画面先黑一下再淡开，镜头切到站在场景里的几个角色，底部白色对白面板依次出现字幕（说话者有头像的，头像显示在他站位的那一侧）。
- 字幕是逐字打出来的（和对话一样），打字过程中点一下画面会把当前这句直接补全显示，不会跳到下一句；演出里出现「▼ 点击或按空格继续」提示时（字幕打完才会出现），鼠标点一下画面，或按确认键（空格 / 回车 / 手柄 A，和对话的推进键一样）才会继续（没停顿、字也打完时点画面不会有反应，也不会跳过）；不想看时按住跳过键（左 Ctrl / 手柄 RB，和对话的跳过键一样），或者用鼠标按住画面右上角的「跳过」文字，效果一样，约 1 秒直接结束这段演出。
- 画面左上角有「LOG」按钮（键盘 H、手柄 LB），点开能看到这段演出已经念过的台词，和对话的历史面板是同一个；开着的时候这段演出会先暂停（不出新字、不能推进 / 自动 / 跳过），关掉才接着播，新出现的停顿点不会被错过。
- 画面右上角有「自动」按钮（键盘 A、手柄 Y），点一下开启后，遇到「▼」停顿点会等字幕打完、再等一小段时间自动继续，不用一直手动点；这时候手动点一下继续，「自动」不会被关掉，要再点一次「自动」才关。
- 播完（或跳过）后对白面板收起、镜头切回原来的视角，世界恢复：如果这段演出是走进区域触发的，玩家可以继续走动；如果是对话中插播的，对话框重新出现，接着说下一句。
- 演出进行期间，原来的探索 HUD、任务栏、对话框都会先隐藏，播完按进来之前的状态恢复（如果进来之前它本来就是藏着的，比如对话里插播演出，播完也不会把它擅自亮出来）。
- 同一段演出只播一次，播完（不管是正常播完还是跳过）都会记住，再次走进同一片区域或再次触发不会重播。
- 演出期间 Esc 不会把它关掉，和对话一样。

## 3. 规则

- 同一时刻只能有一段演出在播，重复拉起会直接抛错（和对话服务同样的规则）；场景触发区在演出正播放时进入不会再触发一次。
- 每段演出有三个独立开关（挂在演出预制体上）：**是否可跳过**、**是否暂停世界**（`timeScale = 0`）、**是否隐藏 HUD**（连带隐藏对话框所在的弹窗层）；默认三个都开。
- 跳过：长按跳过键满配置的秒数（默认 1 秒）直接结束，结果记「已跳过」；自然播完记「已完成」；两种结果都会写进「已播过」列表，一次性演出不会因为跳过而下次继续弹出。
- 停顿点（▼）：时间轴走到「等待输入」标记就自动暂停，必须按确认键才会继续，不会自己过去。
- 三种挂载方式：**场景触发区**（走进去播，可设「只播一次」）、**场景加载即播**、**对话某一句之前插播**；任何模块的代码也能直接按编号拉起一段演出。
- 对话插播：演出播放期间对话框隐藏、不推进、不收玩家输入（和对话本身「被遮挡」时的状态一样）；演出结束后对话自动接着显示下一句台词。
- 演出播放期间不存档；中途关游戏重进会当成没播过，从头再播一次（一次性演出如果之前已经完整播过或跳过过，则仍然不会再播）。

## 4. 策划 / 动画师能改什么

**每段演出（在演出预制体上）：**

| 想改什么 | 在哪改 | 字段 | 改了影响什么 | 备注 |
| --- | --- | --- | --- | --- |
| 是否可长按跳过 | 演出预制体根上的 `PerformanceStage` 组件 | Skippable | 关掉后玩家长按无效，只能等自然播完或按确认走完每个停顿点 | 默认开 |
| 演出期间是否暂停世界 | 同上 | Pause World | 关掉后角色仍能走动，画面不冻结（其余开关各自独立） | 默认开 |
| 演出期间是否隐藏 HUD / 对话框 | 同上 | Hide Hud | 关掉后 HUD 层与弹窗层（含对话框）不隐藏 | 默认开 |
| 谁出场、站在哪 | 演出预制体里的 `Actors` 站位根（见 8.6） | — | 决定舞台上有哪些小人、各站在哪 | 演员名单同时要填（见 8.3） |
| 说什么字幕、什么时候停顿、配什么动作与音效 | 打开演出编辑器（见第 8 节）里的时间轴，编排字幕 / 动作 / 音效三条轨 | — | 决定这段演出具体演什么 | 改完点「校验」 |

| 进场黑场淡开时长 | 同上 | Fade Seconds | 0.25 秒 | 0 = 立即，不做渐变 |
| 停顿提示符 | 同上 | Hold Prompt Text | `▼ 点击或按空格继续` | |

**挂载点（决定一段演出什么时候被拉起）：**

| 挂载方式 | 在哪配 | 字段 | 备注 |
| --- | --- | --- | --- |

## 6. 已知限制与还没做的

- **表情轨暂时用不上**：表情轨只认程序里的「演员」组件（`PerformanceActor` 的具体实现），工程里现在一个都没有（旧的立绘占位演员已随旧演出方式删除），所以新建演出也不带表情轨；序列帧小人要按时间轴换表情，得先请程序加一个实现。
- **没有相机运镜预设**：构图靠时间轴自带的位移 / 缩放动画自己摆，没有镜头语言的现成模板。
- **不做配音与口型**：设计支柱明确不做配音（roadmap D3 备注）。
- **演出中不能存档**：也不支持中途暂停后从中途恢复，中途退出重进会从头再播一次。
- **触屏专属操作延后**：跳过 / 确认现在只有键鼠 / 手柄路径，触屏按钮延后到移动端移植阶段（PC 优先）。
- **演出内不能插分支选项、不能多段并行、不能在演出里嵌一段对话**，这些明确不在本期范围内。

## 7. 和其他模块的关系

- 被 [对话](dialogue.md) 调用：对话树节点的 `performance` 字段可以在某一句台词之前插播一段演出；插播时对话框隐藏，演出结束后对话继续显示下一句。
  **摆在哪**：世界舞台演出摆在「说话的 NPC」脚下——玩家找 NPC 对话时自动以这个 NPC 为锚点；程序从代码拉起对话时要把 NPC 一起传进去
  （`DialogueService.PlayAsync(编号, NPC)`），不传的话舞台会落到世界原点、掉到地面以下。插播期间场景里的玩家、NPC、巡逻怪（连同头顶名字和标记）会自动藏起来，
  只留舞台上的小人，演出结束后原样回来；这一条不用配置，也不能单独挑某个 NPC 不藏。
- 依赖 Core 服务：世界暂停（演出期间冻结世界）、UI（全屏对白面板显示进场黑场与字幕，整层隐藏 HUD / 对话框）、资源（按 Addressables 地址实例化演出预制体）、存档（记住哪些一次性演出已经播过）、输入（复用对话的确认 / 跳过按键，没有单独的按键图）。
- 依赖 Unity 官方 Timeline 包编排字幕 / 动作 / 音效等轨道。
- 依赖 URP 相机：播放时舞台相机接管画面（剔除遮罩、清屏、渲染器等从主相机拷贝，主相机暂停渲染场景），因此与 [探索表现](isometricexploration.md) 共用同一个主相机与渲染管线分档。
- 演员是 [角色小人](characterpuppet.md) 的序列帧小人预制体。

## 8. 给动画师：怎么做一段演出

### 8.1 新建与打开

1. 打开菜单 **`21Days/演出/演出编辑器`**。
2. 在工具栏「新建演出…」旁边的输入框填一个 id（小写字母 / 数字 / 下划线，如 `perf_intro`），点后面那个按钮——它的文字是**「创建」**（不是「新建」），会一步建好预制体、时间轴、图层和 Addressables 登记。
3. 新建后你拿到的是一个**世界舞台空壳**：**三条空轨道**（字幕 / 动作 / 音效，没有表情轨，原因见第 6 节）；时间轴是**固定时长模式**，默认 **8 秒**；预制体里有舞台相机 `StageCamera`（透视、URP Base、没打 MainCamera 标签，默认构图和村口示例一样：在舞台根后上方、微微俯视）和一个空的演员站位根 `Actors`，演员名单是空的。演员要自己放进 `Actors`（做法照村口示例，见 8.6），动作轨的绑定槽也要自己把演员的 `Animator` 拖进去。
4. 点「打开时间轴」，Unity 的 Timeline 窗口会显示这三条轨道，以及一条放「等待玩家确认」停顿标记的标记轨。拖时间线就能实时看到效果（拖动预览不会触发停顿标记，见 8.2）。

### 8.2 逐轨怎么摆

**字幕轨**：轨道空白处右键新建一个字幕片段，填两项——**说话者**（留空 = 旁白，面板隐藏名字栏）、**正文**。片段本身的起止时间就是这句字幕在画面上显示的区间。**容易踩的坑：字幕是硬切换，不支持混合也不做淡入淡出**，两句衔接就是这句消失、下句出现，想要间隔就在片段之间留空。正文没写会标红：「这条字幕还没写正文。」片段上会自动显示「说话者：正文前 12 字」方便你认哪句是哪句。

**表情轨**：新建演出不带这条轨，现在也没有演员能绑（见第 6 节）。等程序给小人加上「演员」组件后再用：在 Timeline 窗口里手动加一条表情轨，把演员拖进轨道左侧的绑定槽，再新建表情片段，填**表情名**——必须和演员表情列表里的名字**一字不差**（大小写敏感）。**容易踩的坑：片段开始的一刻切一次表情，片段结束不会自动回退**，两句字幕之间的空白会保持上一个表情，想换回来要再放一个片段指定原表情。轨道没绑演员时片段会标红：「表情轨道没有绑定演员。」表情名对不上会标红：「演员『X』没有表情『Y』。」（校验窗口里的对应文案见 8.4。）

**动作轨**：普通 Unity `AnimationTrack`，没有本模块自定义的语义，直接把动画片段（`AnimationClip`）拖进去即可，绑定对象是演员（小人）身上的 `Animator`（模板不预先绑，演员放进 `Actors` 后自己拖进绑定槽）。

**音效轨**：普通 Unity `AudioTrack`，拖入音频片段（`AudioClip`），按 Unity Timeline 通行规则播放，没有自定义行为。

**停顿标记**：在最上面的标记轨里对应时间点新建一个 `HoldMarker`，可以填一句备注（`label`）——这句话**只给你自己看，不会显示给玩家**。时间轴走到这个点会自动暂停，必须玩家按确认键（点击画面 / 空格 / 回车 / 手柄 A）才会继续，不会自己走过去；**只在真正播放时触发一次，拖时间线预览不会误触发**，你可以放心拖着看效果。**容易踩的坑：停顿标记不能放在 0 秒处或总时长处（含边界）**，放错了会标红：「停顿标记放在了时间轴开头或末尾之外，玩家可能等不到它。」标记旁边会画一个「▼」提示。

**总时长**：新建演出默认是固定时长模式（Fixed Length），默认 8 秒，在 Timeline 窗口顶部可以直接改数字。总时长是 0 秒会被校验拦下：「时间轴总时长是 0 秒，播出来一闪就结束。」

**可以直接抄的节奏**（来自世界舞台示例 `perf_sample_scene_talk`）：每句字幕片段 **4 秒**，句与句之间间隔 **0.3 秒**，停顿标记放在每句片段**结束前 0.1 秒**（必须落在片段内部，▼ 才会跟着字幕一起出现，不会卡在空白期），总时长 = 最后一句结束时间 **再加 0.5 秒**留尾。

### 8.3 舞台上要填的

- **演员名单（`PerformanceStage` 组件的 `cast`）**：每条是「说话者 → 头像 → 站位」。说话者要跟字幕片段里的「说话者」字段**一字不差**（大小写敏感）才会显示头像，对不上不报错，只是这句不带头像（校验器给 Info 提示）；同一个说话者填了两条，**只有第一条生效**；说话者留空的那一条永远匹配不上任何字幕。这三种情况校验都会标黄。站位（左 / 右）按这个说话者在舞台上的实际站位配——站在画面左边的角色配左，站右边的配右，决定该角色说话时头像出现在对白面板左侧还是右侧头像位。
- **演员不限图层**：演员就站在世界里，舞台相机播放时会拍主相机能看到的全部图层再加 `Performance` 层，校验器不查图层。用演出编辑器新建的舞台整棵树在 `Performance` 层（主相机平时不拍这一层）；你往 `Actors` 里放的小人保持它自己的图层即可。
- **`PlayableDirector` 必须和 `PerformanceStage` 挂在同一个物体（舞台根）上，不能拆开**：停顿标记的通知、字幕轨道找字幕面板输出端，都是发给「Director 所在物体上的 `PerformanceStage`」，拆开了这两样都会失灵（且不会报编译错误，只会运行时不动）。

### 8.4 校验对照表

点「校验」会按 Error（红）/ Warning（黄）/ Info（提示）分级列出问题，文案抄的都是校验器原文。

**Error（必须改，否则播出来一定不对）**

| 提示文案 | 意思 | 你怎么修 |
| --- | --- | --- |
| 「X」根物体上没有 PerformanceStage 组件，它不是一段演出。 | 校验的这个物体压根不是一段演出的预制体 | 确认选中的是演出预制体；正常用演出编辑器新建不会出这个问题 |
| 根物体上没有 PlayableDirector，时间轴没地方播。 | 舞台根缺 `PlayableDirector` 组件 | 补一个 `PlayableDirector`（模板新建的都带着，一般不会缺） |
| PlayableDirector 没有挂时间轴资产（Playable 一栏是空的或不是 Timeline）。 | Director 的 Playable 栏没接时间轴 | 把对应的 `.playable` 资产拖进 Director 的 Playable 字段 |
| 时间轴总时长是 0 秒，播出来一闪就结束。 | 见 8.2「总时长」 | 把 Timeline 窗口顶部的总时长改成大于 0 |
| PerformanceStage 的舞台相机（Stage Camera）没接，演出画面出不来。 | Stage Camera 槽是空的 | 把舞台相机物体拖进 `PerformanceStage` 的 Stage Camera 槽 |
| 表情轨「X」没有绑定演员（轨道左侧的绑定槽是空的），表情不会切换。 | 见 8.2「表情轨」 | 把演员拖进表情轨左侧的绑定槽 |
| 表情轨「X」在 Y 秒处要切「Z」，但演员「W」没有这个表情。 | 见 8.3 | 去演员的表情列表里补上这个名字（大小写要一致），或把片段里的表情名改成列表里已有的 |
| Addressables 里没有把这个预制体登记成地址「X」，游戏里按这个 id 播不出来。 | 地址没登记 | 正常新建都会自动登记；手动挪过预制体或改过地址的话，去 Addressables Groups 窗口把地址改回和 id 一致 |

**Warning（可能不对，需要你看一眼）**

| 提示文案 | 意思 | 你怎么修 |
| --- | --- | --- |
| 舞台相机应为 URP Base（Render Type 改成 Base）：它要接管整个画面，而不是叠在主相机上。 | 相机类型不对 | Render Type 改成 Base |
| 舞台相机应为透视相机（Projection 改成 Perspective），否则看不出纵深。 | 相机是正交的 | Projection 改成 Perspective |
| 舞台相机打了 MainCamera 标签：演出期间 Camera.main 可能取到它，服务就找不到真正的主相机。 | 舞台相机误打了标签 | 把舞台相机的 Tag 改回 Untagged |
| 演员名单第 N 条没填说话者，这一条永远匹配不上字幕。 | 见 8.3 | 补上说话者名字，或删掉这条空行 |
| 演员名单里「X」出现了不止一次，只有第一条生效。 | 见 8.3 | 删掉多余的重复行，只留一条 |
| 演员名单里「X」没拖头像，对白面板不会显示头像。 | 见 8.3 | 把对应角色的头像 Sprite 拖进这一条的 Avatar 槽 |
| 字幕轨「X」在 Y 秒处的字幕片段没有写正文。 | 见 8.2「字幕轨」 | 把这条字幕片段的正文填上 |
| 停顿标记在 X 秒，落在时间轴开头或末尾之外（总长 Y 秒），玩家可能等不到或刚开场就卡住。 | 见 8.2「停顿标记」 | 把停顿标记拖到 0 秒与总时长之间 |

**Info（提示，不影响状态灯）**

### 8.5 试播与挂载

1. 编好后点「校验」，参照上面的对照表把问题改到没有红项（Error）为止；黄字和提示建议看一眼，不强制改。
2. 从 Boot 场景进 Play（点标题「开始」进入游戏），回到演出编辑器窗口点「试播」，能在游戏里实际看一遍这段演出的效果。
3. 挂到游戏里怎么触发，见第 4 节「挂载点」表：场景触发区、场景加载即播、对话某一句之前插播三选一。

### 8.6 世界舞台（放演员、接场景）

所有演出都是**世界舞台**：演员直接站在 3D 场景里说话，舞台相机接管整个画面——适合「玩家在探索场景里，几个角色围在原地对话」这种场面，对标明日方舟活动探索地图的对话演出。「创建」给的是空壳（见 8.1），演员照示例 `perf_sample_scene_talk`（见第 5 节）放：在 `Actors` 下建 `Actor_<名字>`，里面建 `PuppetVisual`（挂 `CameraBillboard`，目标相机拖舞台相机），再把小人预制体 `Chibi_<名字>` 拖到 `PuppetVisual` 下，停用小人上的 `ChibiPuppetMotion`（舞台上不走路）；要朝左站的把小人的 X 缩放改成 −1。演员名单按站位填左 / 右（见 8.3）。

播放时会发生什么：

| 项 | 行为 |
| --- | --- |
| 舞台相机 | 透视、URP Base，接管整个画面（渲染主相机能看到的一切 + Performance 层） |
| 主相机 | 演出期间保持存在（`Camera.main` 不能变空），但不再实际渲染场景，结束后恢复 |
| 摆放锚点 | 演出实例会被摆到调用方给的世界位姿上（比如触发器的锚点物体、对话里说话的 NPC）；没给就停在预制体自己的位置 |
| 演员图层 | 不限图层，演员就是站在世界里的物体 |

场景侧的触发器（`PerformanceTrigger`）要多填三项：**`anchor`**（一个世界锚点物体，决定演出实例摆到哪个位置、朝哪个方向）、**`hideActorVisual`**（演出期间是否把玩家自己——包括头顶名牌——藏起来）、**`hiddenDuringPlay`**（演出期间要一起藏起来的场景物体，比如和舞台上同一个形象的 NPC、还在场景里走动的巡逻怪、会飘在画面里的头顶标记）。

程序侧的实现细节见[开发手册 6.16 节](../developer-guide.md)与[模块指南「世界舞台」一节](../../ai-docs/docs/modules/performance/performance-module-guide.md)。
