## 问题 / 动机

本作核心动作是「辨认」：通灵视回答「有没有」，镜回答「是谁」，被妖正面击溃时镜替挡并裂。
工程里这条链一环都没有，后续的收押、画皮、弱点识破、结局都读「辨认结果」，没有它无从开工。
这一波把辨认链的前半段做成可玩、可回放的 demo，接法按正式标准走，内容与美术占位。

## 目标（可度量）

- G1 玩家能在 SampleScene 里照人、照妖、照自己，看到四种不同结果。
- G2 照妖的结果取决于「场景信息」：没拿到线索只得模糊轮廓，拿到后照见真形。
- G3 在特定环境条件下，玩家能察觉附近有妖，但得不到名字。
- G4 被妖击中三次依次出现三道裂痕，第三道进入「镜碎」页并重开本场。
- G5 每只妖按同一张数据表定义，加一只妖不改代码。

## 范围 / 非目标

做：
- 妖物数据表：化形名、真形名与描述、真形图、破绽描述、执念、族属、照见真形所需线索、能否收押、能否制面具。后三列本波只存不用。
- 照镜：朝向前方的扇形范围内选一个对象；结果分「照人正常」「照物正常」「模糊轮廓」「真形」「照不到」五种；另有独立的「自照」动作，结果恒为空白。
- 镜缘刻痕：每次照镜的结果画面上都能看到律条刻痕文字（占位文案）。
- 辨认记录：每只妖是否已照见真形、是否见过模糊轮廓，进存档。
- 通灵视：玩家处于「雨 / 夜 / 昏暗」任一条件的区域时自动生效，附近的妖身上出现不带名字的影子提示；离开区域即消失。
- 镜裂：被妖击中一次多一道裂痕；裂痕越多，照镜的作用距离越短、屏幕可见范围越小；裂痕显示在镜的图标上，**不出现血条或生命数字**。
- 剧情裂痕计数：与击中裂痕分开记，只缩减可见范围，不计入三裂；本波只提供触发接口，不接任何剧情。
- 镜碎：第三道裂痕后出现只有「镜碎」二字的页面，任意键后重开本场（回到出生点、裂痕清零、任务与拾取进度保留）。页面不出现「读档」字样。
- SampleScene demo 布置：一只巡逻的妖、一只混在村民里不攻击的妖、若干普通人、一个通灵视生效区、一只装着线索的物资箱。
- 回放验证与 EditMode 测试。

不做：
- 照镜消耗耐久（矛盾 #4 的 demo 默认：只有被击中才裂）。
- 失败用法「照镜背 / 照水面」（需要可照的场景物件，随 [09] 镜界层再做）；「照远处」以「照不到」体现。
- 镜照镜进入镜中世界、收押、归还、画皮、账、追逐躲藏（后续波次）。
- 妖在世界里切换成真形外观：真形只在镜中显示。
- 天气 / 昼夜系统：环境条件是区域上的静态标记。
- 触屏控件（PC 优先）。

## 玩家故事 / 关键场景

- 作为玩家，我对着村民按照镜键，镜里是这个人本身，从而知道他是人。
- 作为玩家，我对着一个举止古怪的「村民」照镜，镜里只有模糊轮廓；我在物资箱里找到一封旧信后再照，镜里出现了它的真形与名字，从而确认它是妖。
- 作为玩家，我按自照键，镜里只有身后的景物，没有我。
- 作为玩家，我走进昏暗区域，看见某个方向有「多了一层的影子」，但不知道那是谁，于是去照。
- 作为玩家，我被巡逻的妖追上击中，镜图标多了一道裂痕，视野边缘暗了一圈；第三次被击中时屏幕只剩「镜碎」二字，按键后我回到出生点重来。

## 验收标准

- [ ] V1 照人：扇形内最近对象是人时，结果为「照人正常」，显示该人的名字与形象。（EditMode 断言 + 回放）
- [ ] V2 照妖且线索不足：结果为「模糊轮廓」，不显示真形名；该妖记为「见过轮廓」。（EditMode + 回放）
- [ ] V3 照妖且线索齐（或该妖无线索要求）：结果为「真形」，显示真形名、描述与真形图；该妖记为「已照见」，读档后仍为已照见。（EditMode + 回放 + 存档往返测试）
- [ ] V4 自照：结果恒为空白，无论前方有无对象。（EditMode + 回放）
- [ ] V5 扇形内无对象或对象超出当前作用距离：结果为「照不到」。（EditMode）
- [ ] V6 每个结果画面都显示镜缘刻痕文字。（回放截图肉眼）
- [ ] V7 通灵视：玩家在条件区域内时，作用半径内的妖出现影子提示，普通人不出现；提示不含名字；离开区域提示消失；区域外不出现。（EditMode 条件规则 + 回放）
- [ ] V8 裂痕：被妖击中一次裂痕 +1，镜图标同步显示；作用距离与可见范围随裂痕缩小；全程界面上没有生命数字或血条。（EditMode + 回放）
- [ ] V9 剧情裂痕：触发后可见范围缩小，但不计入三裂、不会引发镜碎。（EditMode）
- [ ] V10 镜碎：第三道击中裂痕后出现只有「镜碎」二字的页面，页面无「读档」字样；任意键后回到出生点、裂痕为 0，任务进度与已开箱子保留。（回放）
- [ ] V11 照镜结果显示期间世界暂停，对话进行中、暂停菜单打开、沉浸模式下照镜键无效。（回放）
- [ ] V12 新增一只妖只需加一行数据表与场景上一个标记组件，不改代码。（任务评审 + 回放里第二只妖即证据）
- [ ] V13 既有回放 Player / Monster / Disguise / Exploration / Session 仍通过；EditMode 全绿；lint、`invariants.py` 零违规；code-reviewer 无 BLOCK；模块三件套登记。
