# 酒肆划拳、正式开场与节点区域教程

日期：2026-10-18。状态：设计获用户“做吧”确认，已实施，验证记录见 tasks.md。

## 范围

先让酒肆中的客甲、客乙和主人都能真正划拳，按输赢饮酒并给出醉后消息；再把正式剧情接到正常新游戏入口，走完梦中驱傩、客店切磋、人间接案、入镜、五店、酒肆主人战斗及战后会面；沿途根据当前剧情节点、所在区域和实际完成情况显示简短教程，玩家始终能自行操作。三家必做店为戏班、衣肆、金银行，可任意顺序完成，客栈提供消息和方向。

用户已选择本轮做到“序章至阶段一 BOSS 战后、妻子会面，形成完整可玩流程”。正式稿在酒肆战后安排殷红出场，下一段坊市巷对白继续交代她与崔皓的关系，因此把这段会面也纳入收束；到她提出带路后停止本轮内容，不进入名册调查。

范围不含阶段二调查及后续关卡、两张皮容量与地面回收、新建完整人间大地图、重新制作现有三店小游戏或新美术动画。沿用已交接的暗杀取皮、本体换皮和三组乔装成果通行规则。

## 玩家流程

正式开场 → 走近李诏阳并完成切磋教学 → 接案、到书库并入镜 → 轮回堂问询 → 坊市潜行取皮和换皮 → 任意顺序完成戏班／衣肆／金银行 → 酒客身份入席 → 划拳获得消息并灌醉主人 → 挑战主人 → 胜利后在楼梯口遇见殷红 → 到巷口完成会面对白。

## 划拳体验

- 每局双方各出 0～5 指，各喊一个双方指头总数。玩家先选出指与喊数，再确认；确认后同时揭晓双方选择。
- 只有玩家猜中：对手喝一杯；只有对手猜中：玩家喝一杯；双方都中或都不中：平局，不喝酒，可以继续。
- 每杯增加 10 点醉意，沿用现有上限、移动与感知效果。甲、乙、主人各自计算醉意。
- 客人达到现有醉酒上限后给对应消息；主人至少喝过一杯后可挑战。酒肆仍检查三组乔装成果与酒客身份。
- 每局显示出指、喊数、实际总数、胜负和饮酒对象。退出不结算未确认的一局，连点不能重复罚酒。
- 用户追加动态难度：各对手根据最近24局历史学习，按玩家平滑胜负表现缓慢调整强度；本局出拳在玩家确认前固定，学习记录随槽保存。该曲线控制策略强度，不保证指定胜率。

## 软引导体验

屏幕边缘显示一条当前目标和一条眼前可做的操作提示。只有当前节点允许、玩家在相应范围、动作尚未完成时，才显示对应操作；完成、离区或进入对白／小游戏／战斗后收起。首次移动、对话、潜行接近、取皮后换皮、三店操作、划拳、挑战和战后会面均有对应提示。

引导不暂停、不强制点击、不替玩家完成动作。三店自由选择时，只显示所在店尚未完成的下一步；未在店内时提示缺少哪些成果，不指定固定通关顺序。提示中的键位跟随当前输入绑定。

## 固定验收标准

| 编号 | 必须达到的结果 | 可判定方式 |
| --- | --- | --- |
| A1 | 三个对象均能完成划拳；四种猜中组合产生正确输赢／平局，饮酒每杯 +10；非法输入、重复确认、退出和换槽不会多结算 | 规则测试穷举合法组合；回放展示玩家胜、负、平及取消 |
| A2 | 从正常标题新游戏进入正式开场，经实际切磋、实际三店成果和酒肆 BOSS 胜利，走到殷红会面结束；全过程不靠调试发物、跳节点或自动判成功 | 从 Boot 运行连续回放；核对剧情节点与玩法结果，保存完整步骤及截图 |
| A3 | 三店能以两种不同顺序完成；缺件不能进酒肆，齐件放行；客甲、客乙醉后给各自消息，主人醉后可挑战，实际醉意带入 BOSS 开场 | 门槛与消息去重测试；正常流程回放检查背包、身份和战斗快照 |
| A4 | 同一区域在错误节点不弹教程；当前节点进入正确范围才显示；离区／完成后收起，区域边界不反复闪烁；教程不阻断移动或抢交互 | 引导选择测试与入区、出区、重入、完成的视觉回放 |
| A5 | BOSS 失败能重试且主线未丢；胜利仅推进一次；在本轮稳定节点退出、继续和切槽后，剧情、成果、消息与教程一致，旧异步结果不能改新槽 | 剧情续接、迟到回调和存读档测试；隔离测试存档回放 |
| A6 | 正常流程中无编译或运行错误，玩法结束后输入、镜头、音乐和 HUD 恢复；规则检查与资产检查通过，开发者能看见并确认回放 | 控制台、定向测试、lint、资产体检与 Showcase 报告；人工视觉确认 |
