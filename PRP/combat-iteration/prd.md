# PRD: combat-iteration（战斗系统迭代）

> 2026-10-14。规则由用户分两轮问答拍板（见「拍板记录」）；策划 A3 / A4 / C9–C13 / C90–C92 未答，这些都是**临时口径**，全部做成配置，策划答复后改配置、不改代码。

## 问题 / 动机

战斗主干已经接通（背后处决、掩体、实时遭遇回写剧情、回合制 BOSS 战），但玩家侧还有五个缺口：

1. **露馅没有后果**：判定能算出露馅，但什么都不会发生。
2. **被追上没有后果**：追逐中被追上只留一条记录，玩家感受不到任何惩罚。
3. **两套战斗互不相通**：打巡逻怪永远进不了回合制；回合制的三种开战方式在 demo 里只到得了「正面攻击」。
4. **BOSS 只会站着等**：只能由玩家按 E 挑战，「被打」开战没有来源。
5. **demo 只有一种怪**：看不出「不同怪不同打法」，也没法在同一场景里同时演示两种被抓后果。

## 目标（可度量）

- G1 露馅有后果：露馅时玩家当场失去借来的身份，当时察觉到玩家的怪物转为敌对并开始追逐。
- G2 被追上有后果：先被击倒（只能慢走、不能攻击），生命归零才算输。
- G3 实时遭遇可升级为回合制：种类配了战斗数据的怪，在三种出手情形下以对应开战方式进入回合制；战后结果回到实时世界与剧情，只结算一次。
- G4 BOSS 会主动发难：察觉玩家后冲上来，嘲讽后以「被打、BOSS 先手」开战。
- G5 一场遭遇支持多种怪同场；demo 新增一只别种类的怪，同一场景里同时看得到「升级回合制」与「被抓击倒」。
- G6 收尾：过期文档修正、受影响回放复跑、视觉验收清单补条目。

三种出手情形的定义：

| 情形 | 判据 | 开战方式 |
| --- | --- | --- |
| 玩家正面出手 | 怪物已警戒或敌对时，玩家的普通攻击打中它 | 正面攻击，玩家先手 |
| 怪物先动手 | 敌对的怪物攻击打中玩家（包括追逐中追上玩家） | 被打，怪物先手 |
| 偷袭未得手 | 怪物尚未察觉玩家时，玩家用普通攻击打中它（没有走背后处决） | 偷袭，玩家先手，怪物开局先掉一截血（沿用现有 20% 占位） |

## 范围 / 非目标

**做**：
- 露馅后果（失去身份 + 察觉者起追），六种露馅原因命中任一都走同一后果。
- 被抓后果（击倒 → 生命归零判输）。
- 实时遭遇升级回合制：三种触发、按种类开关、战后结果回写实时世界、掉落与剧情。
- BOSS 主动发难与重新武装。
- 一场遭遇支持多种怪同场；SampleScene 新增一只别种类的怪。
- 收尾：文档、回放、视觉验收清单。

**不做**：
- **巡逻者乙**是协作者 linch 的线：不接升级、不接处决、不改它的配置。多种类改造如果牵动它的装配，只保证行为不变，并把影响写进报告。
- 普通怪在回合制里的专属招式与 AI：沿用 BOSS 战的规则与占位数值，等 C91。
- 召唤 / 编队、固定追逐：目前没有内容，不接。
- BOSS 视线、BOSS 多阶段变身、BOSS 战掉落奖励、数值迁表。
- 「偷袭 BOSS」：玩法未定（A5、`00` §8.1 #5）。
- 露馅**判定**规则本身：只接后果，不改判定。

## 玩家故事 / 关键场景

- 作为借着身份混进去的玩家，我走进市令的红区时露了馅：身份当场没了，市令转身追我；甩掉它就没事，被追上就打起来。
- 作为潜行的玩家，我绕到市令背后按 F，它当场倒下、掉皮，**不会**进回合制；如果我没绕到位就挥了普攻，就以「偷袭」进回合制，我先手、它先掉一截血。
- 作为被市令盯上的玩家，我正面挥刀会以「正面攻击」进回合制、我先手；我没动手、被它先打中，就以「被打」进回合制、它先手。
- 作为被巡夜人（没配战斗数据）追上的玩家，我会被击倒、只能慢慢爬，再被打到没血才算输。
- 作为走近 BOSS 的玩家，我一进它的红区它就冲过来，嘲讽一句后它先出手；我输了撤退后，它回到原位，我得先走远再回来它才会再冲。
- 作为在村北「较量」剧情里的玩家，这一仗不管是实时打完还是升级成回合制打完，打赢或被击倒都会让这一关结束。

## 验收标准

（「测试」= EditMode 断言；「回放」= Showcase 回放里看得见的检查点。）

**A. 露馅后果**
- [ ] 测试：借着身份时判定命中任一露馅原因 → 身份当场失效；当时察觉到玩家的怪物转为敌对并进入追逐。
- [ ] 测试：后果口径可在配置里切换为「无 / 死亡 / 追逐」，三种配置各一条断言，切换不改代码。
- [ ] 测试：未借身份时不产生露馅后果（负对照）。
- [ ] 回放：借着身份走进市令红区 → 身份失效 → 市令起追。

**B. 被抓后果**
- [ ] 测试：未配战斗数据的怪追上玩家 → 玩家进入击倒状态，生命未归零前这场遭遇不结算。
- [ ] 测试：击倒中生命被打到归零 → 这场遭遇按「被击倒」结算；在剧情战斗阶段内时，剧情走「被击倒」出口。
- [ ] 测试：被抓口径可在配置里切换（至少「无」与「先击倒后判死」两种），切换不改代码。
- [ ] 回放：新怪追上玩家 → 击倒 → 生命归零后结算。

**C. 实时遭遇升级回合制**
- [ ] 测试：配了战斗数据的怪，三种情形各自进入对应开战方式，先手与开局扣血符合上表。
- [ ] 测试（负对照）：没配战斗数据的怪，三种情形都不进回合制，行为与现状一致。
- [ ] 测试：背后处决不进回合制，目标仍当场死亡。
- [ ] 测试：三种触发各自可在配置里单独开关。
- [ ] 测试：回合制打赢 → 怪物死亡并按种类掉落一次，不受「不可击杀」限制；在剧情战斗阶段内走「打赢」出口。
- [ ] 测试：回合制打输 → 与实时生命归零走同一条失败流程；在剧情战斗阶段内走「被击倒」出口。
- [ ] 测试：同一场遭遇的结果只结算一次：剧情不重复推进，掉落不重复发放。
- [ ] 测试：战斗期间实时世界暂停、不可存档；战后玩家回到进战前的位置（沿用 BOSS 战现有口径）。
- [ ] 测试：血量互通（Q1）——进战斗时玩家血量比例等于实时血量比例；出战斗后实时血量按战斗剩余比例写回。
- [ ] 回放：市令的三种升级各有检查点（开战方式、先手、开局扣血、战后结局）。

**D. BOSS 主动发难**
- [ ] 测试：玩家进入 BOSS 红区 → BOSS 朝玩家移动；接触后播放与按 E 挑战相同的嘲讽对白，随后以「被打」开战、BOSS 先手。
- [ ] 测试（回归）：按 E 挑战仍是「正面攻击」、玩家先手。
- [ ] 测试：打输撤退后 BOSS 回到原位；玩家没离开察觉范围前不会再发难，离开再进来后会再次发难。
- [ ] 测试：对话中、剧情演出中、战斗中、BOSS 已被击败时都不发难。
- [ ] 回放：走进 BOSS 红区 → 冲过来 → 嘲讽 → BOSS 先手开战。
