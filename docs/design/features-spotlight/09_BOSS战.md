## 1·一句话

聚光灯在阶段一、六、九各安排了 BOSS 战，序章流程末尾也有一场；大部分 BOSS 战的打法原文还没定，但原文写好了几条绕开硬打的路：用「牙」削弱，用泾龙丹、泾龙面具跳过钱塘君的第一阶段，少让特定信众被消耗来压低分福身的强度。阶段一 BOSS 的回合制规则**原先缺文档、2026-10-07 补交入库**（[sp07](../spotlight/07_回合制作战文档.md)）：进战斗有三种方式、先手各不同，玩家三个招式花怒气、能用道具，BOSS 醉酒四档会在它的回合跳过回合。

## 2·玩家看到什么

以下是按原文拼出的体验，属 [推断]。

- **阶段一**有两套写法。sp02 那套：走完五个场景，在酒肆和阶段一 BOSS 打一场回合制战斗，赢了就知道妻子在哪；开战前或许能先把它灌醉。回合制怎么打见 3.9（[sp07](../spotlight/07_回合制作战文档.md)）：潜行偷袭开战能拿走它 20% 生命并抢先手，正面对着打抢先手，被打则它先手；战斗中每回合出一招、按怒气，道具每场每件用一次；它醉得越深越容易整回合不能动，但它自己也会喝酒回血。sp03 那套：先在戏班、衣肆、金银行打败三个 BOSS（乐官、行首、知金银行都料），拿齐三张面具去官署挑战坊正，赢了拿到进酒肆的一次性钥匙。
- **阶段六**：带着执事皮，或者拿灰衣面具，进分福祠的 boss 房间。先打食教者，一个用很多张「皮」缝出来的怪物，用阶段3 拿到的「牙」可以削弱它；打倒后它变成分福身，排队时被消耗的特定信众越多，它就越强。打赢拿到「空白皮」。
- **阶段九**：在龙窟深处的秘藏房间遇到泾龙鬼，非常难打，可以用「牙」削弱，打赢拿到泾龙丹。最后面对钱塘君：开战前可以先和他交互；他先以人形拿金锁、青玉笏班攻击，血量打空后现出赤龙真身，雷霆、冰雹、雨雪、龙爪、龙咬、龙尾一齐来。手里有泾龙丹或泾龙面具，可以直接跳到龙形那一段。
- 战斗时屏幕顶部有 BOSS 名字和血条，打完可能出现带分数、最大 COMBO、评价的结算界面（sp04 UI 表）。

### 3.4 阶段3 泾阳

- **R15** 阶段3 的 C 层没有 BOSS，只有关键 NPC 老吏和执法者查勘使。老吏「被击败后不可选中，之后给予玩家线索和剧情」；查勘使掉的面具「可直接制服老吏/进入可互动状态」。[原文]（sp03「阶段3 · C 关键怪物」）

### 3.9 回合制战斗（[sp07](../spotlight/07_回合制作战文档.md) 全文）

> 这一节整节来自 2026-10-07 入库的《回合制作战文档》（2026.8.22）。原文写的是通用回合制 + 阶段 1 BOSS，没有写这套只给阶段一 BOSS 用还是所有 BOSS 都用，见 Q17。

**怎么进战斗**：

- **R40** 三种进入方式，先手权各不相同：[原文]（sp07「一、进入战斗」）

  | 进入方式 | 触发条件 | 触发效果 |
  | --- | --- | --- |
  | 玩家偷袭攻击 | 玩家潜行并偷袭怪物成功，玩家攻击 BOSS，进入战斗 | 玩家先手；**BOSS 生命值减少 20%** |
  | 玩家正面攻击 | 玩家在怪物的警戒 / 敌对区域内，或怪物正处于警戒 / 敌对状态，玩家攻击 BOSS | 玩家先手 |
  | 玩家受到攻击 | 同上条件下玩家被 BOSS 攻击 | **BOSS 先手** |

- **R41** 进入战斗后玩家进入**新的战斗场景**——战斗不在潜行关那张地图上打，是切场景的。[原文]（sp07「二、战斗过程」）

**回合怎么走**：

- **R42** 玩家三个招式，都只能在自己回合使用：招式 1 无消耗、用后 +1 怒气；招式 2 消耗 1 怒气、蓄力重击并**减少对方 50% 治疗效果**；招式 3 消耗 3 怒气、重击刺入，并让**玩家接下来的 3 次攻击附带额外伤害**。三个招式都有位移表现：闪身到敌人身前攻击，打完退回原位。[原文]（sp07「二、战斗过程 · 2 战斗规则」）
- **R43** 玩家施放招式后进入敌方回合；也就是说**一个回合 = 玩家出一招 + 敌方行动一次**。[原文]（sp07「二、战斗过程」）
- **R44** 界面上的「玩家状态右下角显示剩余回合」说明战斗**有回合上限**，但上限是多少原文没写（Q18）。[原文]（sp07「二、战斗过程 · 1 画面表现」）
- **R45** 道具在**施放招式之前**使用；道具的显示规则是「可以使用则高亮，用过了则置暗；未拥有或在之前战斗时用过了，则不显示」——**一次战斗内每件道具只能用一次**。[原文]（sp07「二、战斗过程」）

**打谁、怎么被打**：

- **R46** 阶段 1 BOSS 的醉酒：进入战斗时继承场景外的醉酒值；醉酒值显示在**血条下面**、状态显示在**血条上面**（玩家没有醉酒值，但有状态）；四档效果在**怪物回合**结算——正常 0–49 无效果、微醺 50–79 有 20% 概率跳过回合、薄醉 80–99 有 40% 概率跳过、酩酊 100 则 100% 跳过且醉酒值下降 50、持续 2 回合；跳过回合时屏幕中央闪现提示（微醺 / 薄醉 / 醉酒三种文案）。[原文]（sp07「三、1. 阶段1BOSS」）
- **R47** BOSS 三个招式，施放比例 6 : 3 : 1：招式 1 普通攻击；招式 2「饮酒」增加 30 醉酒值、回复 10% 生命值、下次招式 1 伤害 +30%；招式 3 按自身状态分两种——正常 / 微醺时造成单次高额伤害，**薄醉时同样高额伤害并晕眩玩家 1 回合**。[原文]（sp07「三、1. 阶段1BOSS」）由此：BOSS 自己会喝酒（醉酒值不是只减不增），而**玩家被晕眩时怎么过回合**原文没写（Q18）。
- **R48** 回合制界面的元素与状态：顶部「可用道具」格、底部三个招式格、右侧怒气槽、左边的玩家状态；招式怒气够则高亮、否则置暗，怒气满时怒气槽颜色更鲜艳；鼠标悬停弹出详细信息。[原文]（sp07「二、战斗过程 · 1 画面表现」）[13](13_系统界面清单.md) 的 UI 表里**没有这套回合制界面**，只有 BOSS 血条与结算界面，见 Q19。

## 6·与叙事的咬合

以下对应关系除注明 [原文] 的以外都是 [推断]。

- **钱塘君取自《柳毅传》**：龙形一段就是原典文字（R30）。原典里钱塘君因为侄女（洞庭龙女）被泾川龙之子虐待，飞去泾阳把那条龙吃了；sp01 阶段九写钱塘龙君「坦然承认吃了泾川龙第二子」，和原典对得上。
- **泾龙鬼**也许就是那条被吃掉的泾川龙第二子的鬼魂。打败它拿到的泾龙丹能削掉钱塘君的一个阶段，是「被吃者向吃者讨债」。
- **「牙」**：sp01 阶段五写民间祠堂供奉「龙牙」，阶段七写信众「开始信仰那条“被吃的龙”」[原文]。拾骨人篮子里的牙、半龙侍掉的牙，都可能是那条龙的遗骨。用龙牙削弱以「被吃之人」为核心的食教者和泾龙鬼，形成一条因果线。
- **食教者**是「多个“皮”缝合而成」，直接用上了「傩戏+画皮+志怪」[原文] 里的画皮。
- **分福身**是「被吃之人的集合体」，对应 sp01 阶段七「他们供奉的神明是空的，或者说就是那些“失踪的人”」[原文]。排队时少让一个特定信众被吃，分福身就弱一分：玩法和剧情是同一件事。
- **钱塘君的结局是收押**：阶段十二「关在井底」[原文]，sp04 模型表也有「泾阳·井底：关押钱塘龙君的井」「坊市·洞庭府：钱塘龙君居所」[原文]。BOSS 战打赢之后要接对质和收押，而不是杀死（Q12）。
- **阶段一 BOSS** 守着「妻子的位置」，是整部主线（寻妻）的第一个台阶。

## 8·设计约束与检验问题

**约束** [推断]：

1. 「本体打不过任何怪物」的前提下，每个 BOSS 都要至少有一条非正面的途径：削弱、跳过、规则或身份。原文已经给了牙（食教者、泾龙鬼）、泾龙丹 / 泾龙面具（钱塘君）、排队时少让特定信众被消耗（分福身），醉酒对阶段一 BOSS 也可能算一条；乐官、行首、知金银行都料、坊正还一条都没有。
2. 道具链很长而且跨阶段：钱塘君的跳过 ← 泾龙丹 ← 泾龙鬼 ← 牙 ← 阶段3 拾骨人或阶段九半龙侍；泾龙面具还要阶段六的空白皮。漏拿了怎么办，要不要保底，要先想好。
3. 分福身的强度挂在排队阶段的表现上，所以玩家在排队时要能看到「已经有几个特定信众被消耗」，否则这条因果感受不到。

**检验问题**：

- BOSS 战到底是什么形式：回合制（sp02）、音游 / 小游戏（sp00、sp04），还是 sp03 写的有血量、有攻击招式的动作战斗？三种写法得先统一。
- 钱塘君的「战斗前可交互」，和 sp01 的「对质 → 收押」是同一件事吗？要是对质成功就收押，还打不打？
- 牙用一次就没了的话，食教者和泾龙鬼都想削弱，玩家需要至少两颗。原文的两处来源够不够？
- 用执事皮直达 boss 房间很方便，但它把特定信众变成福事，会不会让分福身更强？这算设计好的取舍，还是陷阱？
