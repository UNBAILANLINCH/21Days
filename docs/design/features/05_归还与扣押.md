## 1·一句话

对一个已被照见的存在做出去处裁定——关住、放回、归还、驱逐，或终章的送入轮回；每一种都有人认同，每一种都要付代价，裁定的结果会刻在镜背上。

## 3·规则

- **R1** 裁定对象是「一个存在」，不限于被收押的妖：第一章的两次裁定分别落在龙（C8）与敬元颖（D2）身上。[原文]（1_核心 §5；story C8、D2）
- **R2** 两个选项通向不同而不分优劣的结果，各得一样、各失一样。[原文]（1_核心 §3 支柱2）
- **R3** 系统不引导、不评判：不标「正确」、不给善恶值。[原文]（1_核心 §3 支柱2「放弃了」；反面清单「不做道德评判」）
- **R4** 当场裁定的基本对立是「收押（→扣押）」对「放归 / 捞出」。[原文]（story D2；3_角色 §2.4）
- **R5** 两边的代价与所得各不相同：扣押得助手效果、付受害者之灵的嚎哭与一笔账；捞出得报恩——「不是给能力，是给一条命」。[原文]（story D2）
- **R6** 「驱逐」是另一种去处：主角对龙「不杀，改判为驱逐」；驱逐也是妖界自己的手段之一。[原文]（story §1.1、C8；2_世界观 §5B）
- **R7** 已扣押、已制成面具的妖，若佩戴者自愿归还，妖可离皮。[原文]（2_世界观 铁律 3）。归还后面具失效 [推断]（依据 铁律 3「妖并未死，仍在皮里」——本事来自皮里的妖）
- **R8** 归还可销账。[原文]（2_世界观 铁律 4）
- **R9** 摆渡人可裁定豁免；豁免与归还是两回事。[原文]（2_世界观 铁律 4；story §1.4 L1「归还不是豁免」）。两者具体差在哪 [待定]
- **R10** 「送入轮回」是只有摆渡人在终章才能做的去处，不可逆，见 [12](12_断其去处.md)。[原文]（2_世界观 §2 门 3；3_角色 §1.5）
- **R11** 裁定若出于人情改动律条既定的刑，即触犯铁律 6；第一章 C8 主角就这样做了，后果是龙族上门「程序性质问」。[原文]（story C8、§4.4；2_世界观 铁律 6）
- **R12** 裁定结果刻进镜背第三行：玩家会看见自己整章写下的那句判断。[原文]（story D9、D10）。第三行由哪一次（或哪几次）裁定生成 [待定]
- **R13** 当场裁定之后能否反悔：扣押 → 归还可以（R7、R8）[推断]；放归 / 捞出之后能否再收押 [待定]；送入轮回不可反悔 [原文]（门 3）

## 7·对应工程现状

- **可承载模块**：Dialogue（「条件选项」）可呈现 D2 这类选择；Narrative（「事件驱动的剧情阶段迁移」）可承载裁定结果的状态；Performance 可承载 D10 镜背第三行这类短演出。「裁定」「归还 / 豁免」本身无对应模块。
- **roadmap**：G 组无对应行；最接近 G6「三结局硬分支」（Narrative 阶段机可承载）。无定义项可逐条对应。

## 8·设计约束与检验问题

- 不做道德评判、不做强引导（反面清单；支柱 2「放弃了」）：裁定界面不出现「正确」「善 / 恶」字样，参照 story A3「无音效、无高亮、无『重要选择』标记」的做法 [推断]。
- 硬分支只在终章，上限 3 条（反面清单）：第一章的裁定只能算软分支，不改结局可用性 [推断]（依据 1_核心 §1 分支规模对「硬分支 / 软分支」的定义；story 另有「硬后果」一词，指章内不可逆结果，与硬分支不是一回事）。
- 不许以人情断律条（铁律 6）：人情裁定必须有账面后果，不能白改 [推断]。
- **检验问题**（支柱 2）：这个选项，是否两边都有玩家认同的理由？若有一边明显更对，改写。

## 9·待定与开放问题

1. **术语口径待拍板（重申）**：1_核心 §5 把「收押妖灵」与「归还／扣押」列为两个动作；story D2 把「收进自己的镜里 → 扣押」当作一个选项，与「捞出来放回人间」对立。本系列按「收押即扣押、归还是对已扣押者的事后改判、捞出 / 放归是当场不收押」写（[推断]），**需策划确认**；若策划采用「归还 = 当场放回」，则第 3 节 R7、R8 与去处表要改。
2. **「归还不是豁免」**：story §1.4 L1 列为一幕要教的规则，但全文没展开。铁律 4 说二者都能消账。可能的读法：归还销的是「这只妖」的账，豁免免的是「这件事」的账；或归还不抵消主角裁定本身的责任 [待定]。
3. **铁律 4 与 D2 报恩的方向**：捞出敬元颖得到的是「一条命」。这条命指 D3 忠告救下陈仲躬，还是别的？story §4.3 把「证词」列为捞出分支的后果，但 §3.4 流程图里两条分支都进 D3 证词。[待定]
4. **驱逐的性质**：2_世界观 §5B 把驱逐列为妖界的手段；C8 主角用镜改判驱逐。驱逐是执镜者的常规去处，还是只有「改判」时才出现？[待定]
5. **主角何时算摆渡人**：铁律 4 的「豁免」、门 3 的「送入轮回」都要求摆渡人；3_角色 §1.5 说终章「继任后」。第一章 C8 改判算不算越权？龙族「凭什么改判」的质问似乎正是这个意思 [推断]。
6. 镜背第三行是一句固定选项文本、按选择组合拼出，还是自由命名？[待定]
7. 放归后能否再次收押同一只妖；扣押中的妖能否被主角以外的人（崔昭想要镜）放出。[待定]
