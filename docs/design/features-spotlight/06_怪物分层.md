## 1·一句话

聚光灯把每个战斗阶段的怪物分三层：A 底层（数量多、给皮）、B 特定（守着某个地点或职能、给面具或道具）、C 关键（BOSS、执法者、关键 NPC）。本文按阶段把它们整理成一张总表。

## 2·玩家看到什么

以下是按原文拼出的画面，属 [推断]。

- 每张图上最多的是一种底层怪（坊市的妖民、泾阳的溺者、分福祠的信众、龙窟的水族），杀掉就能拿到这一阶段通用的「皮」。
- 店铺、关卡门口、供桌、房门这些要紧的地方，有驻守、巡逻或守门的特定怪，各自管一样事：维持秩序、核验身份、分发福事、召唤巡逻队。杀掉它们能拿到面具、钥匙或一次性道具。
- 每个阶段收尾时是关键怪物：BOSS（阶段六、阶段九还有两阶段战），或是执法者、证人这样的剧情人物。

## 3·规则

### 3.1 分层规则

- **R1** sp03 给每个战斗阶段的怪物分了三层：A 底层怪物、B 特定怪物、C 关键怪物。阶段九的 B 层原文写作「B 特殊怪物」，其余三个阶段写作「B 特定怪物」。[原文]（sp03 各阶段）
- **R2** A 层的共同点：场景里常见、数量多，击杀后掉这一阶段的「皮」（妖民→普通皮、溺者→湿皮、信众→信众皮、水族→水族皮）。[推断]（由表 3.2–3.5 归纳）
- **R3** A 层条目底下原文还挂着变体：坊市的乐工 / 俳妓 / 学徒，泾阳的户绝民、水痕影，分福祠的特定信众，龙窟的巡逻队。它们在原文里写在 A 条目的下一级。[原文]（sp03 各阶段 A 层）
- **R4** B 层的共同点：绑定一个地点或职能（店铺、守门、分发、检查、召唤），击杀或暗杀后多掉面具、某一阶段的专用皮或功能道具。[推断]（由表 3.2–3.5 归纳）
- **R5** C 层原文列了两类：一类是 BOSS（乐官、行首、知金银行都料、坊正、食教者 / 分福身、泾龙鬼、钱塘君），一类是关键 NPC 和执法者（老吏「关键npc」、查勘使「执法者」）。BOSS 详见 [09](09_BOSS战.md)。[原文]（sp03 各阶段 C 层）
- **R6** 行为分类，原文用过的词：「驻地」「巡逻」「守门」「驻守」「守卫」；另有几种特殊行为：追逐（查勘使「追逐怪物」）、依附环境（水痕影）、排队行进（信众）、集群并跨房间流动（巡逻队）、藏在幻象里（蜃师）。[原文]（sp03，见表中各条）
- **R7** 「驻地」「驻守」「守卫」「守门」是不是同一类行为，原文没区分。本文暂按两类理解：驻地 = 在店铺或区域里原地活动；驻守、守卫、守门 = 守在门口，核验后放行。[推断]
- **R8** 常驻数量原文只给了一部分（见表）；没给数量的怪物标「没写」。[原文]
- **R9** 原文写「可否击杀」的几种说法：不可击杀（籍中吏）、常态不可击杀（查勘使）、无法被常规击杀（户绝民，改用湿皮收服）、持有篮子时不可击杀（拾骨人）。[原文]（sp03 各条）
- **R10** sp02 那套阶段一设计不分层。里面明确叫「怪物」的只有酒肆顾客（「场景内最简单的怪物」），sp04 的「小怪（醉酒的顾客）」写的是「阶段一普通敌人」；其余角色以附身对象的身份出现。[原文]（sp02「场景五 酒肆」；sp04「玩法角色」）
- **R11** sp02 写了一条巡逻规则：每个小怪都有两种巡逻路线，都知可以指派乐正以外的小怪改换路线。[原文]（sp02「场景一 戏班 · 一、角色 · 1 都知」）
- **R12** 层与层之间有钥匙关系：A、B 层掉的东西打开 C 层的门。例如坊正要先集齐三个 BOSS 的面具；阶段六的 boss 房间要执事皮或灰衣面具；龙府门口的籍中吏认泾龙丹或「空白皮」。道具链见 [05](05_皮面具与道具.md)。[推断]

**总表的读法**：下列表 3.2–3.5 里没有标注的格子，都是原文转述，出处见末列；本文推断的格子标 [推断]；原文没写的写「没写」。「层级」一列中的「A·下」表示原文写在 A 条目的下一级，「B·下」同理。

- **阶段六 分福祠**：特定信众随行列前进变矮、到供桌前消失，执事分发的「福事」就来自它们，对上 sp01 阶段七「一个人“成为”了粮」；阶段六「领受“福肉”，但是全程无人解释这是什么」。BOSS 分福身是「被吃之人的集合体」。
- **阶段九 龙窟**：水族、半龙侍、泾龙鬼、钱塘君都属龙族一系，对上 sp01 阶段九的找龙；泾龙鬼也许就是 sp01 里被钱塘龙君吃掉的「泾川龙第二子」。
- **阶段1 坊市**：市令、坊正、行首、都料、都知、乐正多是唐代坊市、行会、教坊的职名，与「镜中妖界长安」的设定一致。

## 8·设计约束与检验问题

**约束** [推断]：

1. 每层的奖励梯度要一致：A 层给通用的皮（量大），B 层给面具或专用道具（每样有明确用途），C 层给钥匙或关键道具（推进主线）。表里「掉落」一栏写「没写」的 B 层怪（阶段1 的都知、乐正、裁衣匠、顾客、金银匠、官证、药师、缄口侍）要补。
2. 主角本体打不过任何怪（[03](03_潜行与暗杀.md) R2），表里写了「可击杀（方式没写）」的怪都要补一条非正面的击杀途径。
3. 阶段1 坊市在原文给数量的条目里就有 23–32 只怪同场。工程现在只支持一只，性能、AI 调度、美术量都要按这个数量规划。

**检验问题**：

- 玩家能不能一眼分清 A / B / C 三层？靠外形、颜色、头顶标记，还是位置？
- 「驻地」和「巡逻」两种怪在同一家店里，暗杀顺序会不会被它们卡死？
- 阶段3 没有标 BOSS 的怪。阶段3 的收尾是老吏还是查勘使？
- 两套阶段一（表 3.2、表 3.6）角色重名（都知、乐正、裁衣匠、顾客、金银匠、官证），行为却不同（例如官证在 sp03 是巡逻怪，在 sp02 是附身后改文书的人）。要用哪一套，等策划定。
