# 角色小人（CharacterPuppet）

> 状态：可用（美术为占位）　·　是否已接进游戏：场景级组件（SampleScene 的玩家、巡逻者与三个 NPC）　·　程序文档：[三件套](../../ai-docs/docs/modules/characterpuppet/characterpuppet-module-guide.md)

## 1. 一句话

用一组组序列帧做出明日方舟风格的 Q 版小人，会待机、会走路、会左右翻面。
它只是角色的「皮」：谁在推角色、为什么推，它一概不管，只看角色动了多少来决定演哪段动画。
不用 Spine / Live2D，用的是按状态出的序列帧 + Unity 自带的动画。

## 2. 玩家看到什么、做什么

- 角色站着不动时，小人循环播放待机帧；角色一走起来就切到走路帧。
- 走得快腿摆得快，走得慢腿摆得慢，但有上下限，不会快到抽搐或慢到像滑步。
- 往屏幕左边走整只小人镜像朝左，往右走朝右；只上下走时保持原来的朝向。
- 对话弹出时世界暂停，小人回到待机动画，不会定格，也不会原地踏步；对话结束后恢复。
- 玩家不直接操作小人；玩家操作的是角色（见 [player.md](player.md)），小人跟着演。

## 3. 规则

- **走 / 停判定**：每 0.1 秒看一次角色移动了多远，换算成速度。
  - 站着时，速度达到 0.15（单位 / 秒）才开始走。
  - 走着时，速度降到 0.05 及以下才停下。
  - 两个阈值之间保持原状态，防止慢慢挪动时在走和停之间来回闪。
- **走路快慢**：走路动画播放倍率 = 移动速度 × 0.53，再限制在 0.8 到 2.8 倍之间。按当前数值：
  - 潜行（1.5 / 秒）→ 约 0.8 倍（顶到下限）；
  - 普通走路（3 / 秒）→ 约 1.6 倍；
  - 奔跑（5 / 秒）→ 约 2.65 倍，走跑步频不同。
- **待机与走路之间的切换**是直接换帧（整帧换图没法混合）。起步 / 停步最多慢约 0.1 秒，肉眼基本察觉不到。
- **翻面**：探索场景里跟随角色原纸片的朝向（由遭遇规则按左右移动决定）；没有原纸片的场景（如验证场景）按屏幕左右方向的移动判断，左右速度不超过 0.01 时不翻。
- **翻面是整只镜像**：帧按朝右画，朝左时整张图镜像，所以不对称的挂件镜像后会换边。
- **暂停**：世界暂停期间强制待机，恢复后重新判断，不会把暂停期间的位移算成一次猛冲。
- 小人不参与任何玩法：不影响碰撞、警戒、攻击距离。状态颜色（潜行、敌对等）染在脚下圆环上，不染小人。

## 4. 策划 / 美术能改什么

| 想改什么 | 在哪改 | 字段 / 资产 | 改了影响什么 | 备注 |
| --- | --- | --- | --- | --- |
| 换小人外观 | `Assets/_Project/Art/Sprites/Characters/<名字>/` | `chr_<名字>_<状态>_<NN>.png`，至少 `idle` + `walk` | 该角色的外观与动作 | 同名目录换帧后请程序重跑生成工具；规格见 [美术手册 3.4](../artist-guide.md) |
| 帧率、脚底锚点 | 同目录可选 `meta.json` | `fps`（默认 12）、`pivot` / `pivotPx` | 动作快慢、角色是否贴地 | 锚点必须所有帧一致，否则原地抖 |
| 起步 / 停步灵敏度 | Inspector 里选 `Assets/_Project/Data/CharacterPuppet/ChibiPuppetConfig.asset` | `Move Start Speed` 0.15、`Move Stop Speed` 0.05 | 慢速挪动时多早开始迈腿、多晚停下 | 停步值要小于起步值，否则会来回闪 |
| 判定间隔 | 同上 | `Sample Window` 0.1 秒 | 走 / 停判断的稳定度与反应速度 | 调小会让走路时闪回待机，不建议动 |
| 翻面灵敏度 | 同上 | `Facing Dead Zone` 0.01 | 多小的左右移动就翻面 | 只在验证场景这类「没有原纸片」的情况下生效；探索场景里不起作用 |
| 走路步频 | 同上 | `Walk Cycle Speed Per Unit` 0.53、`Walk Rate Min` 0.8、`Walk Rate Max` 2.8 | 不同速度下腿摆多快 | 想让奔跑步频快于普通走路，要调高上限或调低系数 |
| 动画与控制器 | 由生成工具产出 | `Assets/_Project/Art/Animations/Characters/<名字>/chr_<名字>_<状态>.anim`、`chr_<名字>.controller` | 播放哪些帧、怎么切换 | 不要手改，换帧后重跑工具原地更新 |

这些是 ScriptableObject 数值，改法（退出 Play 再改、改完保存）见 [策划手册第 3 章](../designer-guide.md)。

**美术换图注意事项**

- 交付规范（目录、文件名、画布、锚点、朝向、帧率）见 [美术手册 3.4 节](../artist-guide.md)。
- 同一角色所有帧同一画布尺寸、脚底锚点同一像素位置；默认朝右画。
- 小人整体高约 1.6 个单位（生成工具的目标高度）。
- 换完图请程序跑一次 `/verify-module CharacterPuppet`，看待机、左右走、翻面、停下的截图；再进 SampleScene 确认能被灰盒环境正确遮挡。

## 6. 已知限制与还没做的

- 五套小人全是占位，正式角色美术未出（roadmap F3）。
- 只有待机和走路：没有转身、奔跑、交互、攻击、受击动作（D6）；D6 依赖走跑切换（A1）和美术方案。
- 整帧换图，没有骨骼形变；动作细腻程度取决于帧数。
- 只能左右镜像，没有背面 / 侧面等多朝向。
- 所有 NPC、怪物如果也要用小人，得各自出一套序列帧并跑一次生成工具。
- 战斗表现是否改用 Spine 尚未决定（roadmap 第 6 节风险 7）。

## 7. 和其他模块的关系

- 被 [isometricexploration.md](isometricexploration.md) 使用：在探索场景里作为玩家与巡逻者的外观，随纸片一起正对镜头、被灰盒遮挡。
- 跟随 [monster.md](monster.md) 的遭遇表现：朝向读取遭遇规则翻好的原纸片。
- 间接依赖 [player.md](player.md)：玩家移动速度决定小人走路步频。
- 与 [dialogue.md](dialogue.md) 配合：对话暂停世界时小人保持待机动画。
