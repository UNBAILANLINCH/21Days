## 1·一句话

主角先天的混血体征：在雨、夜、昏暗等条件下，能隐约察觉"这里有东西"，但看不清、认不出——它只回答"有没有"，"是谁"要交给镜。

## 2·玩家看到什么

| 输入 | 反馈 | 玩家心理 |
| --- | --- | --- |
| 条件满足时进入场景（雨 / 夜 / 灯火昏暗） | 环境里出现"影子"、轮廓，或"影子多了一层"的异样（A4） | "这里有东西。" |
| 顺着影子去看 | 只能看到轮廓，不给名字、不给声音 | "它是谁？"——引向照镜 |
| 条件不满足 | 看不到异样，只剩普通场景 | "要等天黑 / 下雨再来。" |

1_核心 §5 表没有为通灵视单列一行 [原文]；它在体验上是「照镜／辨形」一行"我照见的，和我以为的，是同一个吗？"的前半句——先"以为"，再去"照见" [推断]。

## 3·规则

- R1 通灵视是主角先天能力，来源是混血体征，不是镜给的 [原文]（3_角色 §1.5；2_世界观 §3 16 年前；1_核心 §1）。
- R2 能察觉灵异物件和相关实体的存在，但看不清、听不见、认不出 [原文]（3_角色 §1.3）。
- R3 通灵视不能替代镜；若它能认出是谁，主角就不需要镜 [原文]（3_角色 §1.3 写死理由）。
- R4 只在特定时刻生效，使"看见"成为有条件的资源而不是雷达 [原文]（3_角色 §1.3）。条件清单两处原文不一致，见第 9 节 Q1。
- R5 看见不等于确认，确认必须依靠镜 [原文]（3_角色 §1.3）。
- R6 无直接代价（不耗镜、不耗其他资源） [原文]（3_角色 §1.5）。因为它只给"有没有"、不给"是谁"，所以不算世界观禁区里的"无代价的辨认手段" [推断]。
- R7 它的代价是误判：看见轮廓不等于知道是谁 [原文]（3_角色 §1.5）。误判是否要做成可被系统记录的错误结果（例如错把人当妖去照），还是只停在叙事层 [待定]。
- R8 通灵视显示的内容不区分善恶、不区分种类，只给"影子 / 轮廓" [推断]（由 R2"认不出"引申）。
- R9 作为玩家可用的系统，在序章 P7 回家时正式发放 [原文]（story P7）。P7 之前的 P3、P6 照见异样用的是镜，不是通灵视 [推断]。
- R10 A4 的"西市 · 镜界层"（S9）是通灵视生效时呈现的画面：活人只剩轮廓，异常处"影子多了一层" [推断]（story A4 把"镜界层信息①②"与"通灵视生效条件"写在同一场）。镜界层是否属于通灵视、还是属于镜的窥探，见第 5 节与第 9 节 Q2。
- R11 生效时是否需要玩家主动开启（按键切换视图），还是条件满足即自动显现 [待定]。
- R12 生效时是否有持续时间、范围半径 [待定]；原文只给了"条件"，没给"时长 / 距离"。

## 8·设计约束与检验问题

- 不做全知型任务指引（支柱 3"为了它我们放弃了"）：通灵视不能变成指路箭头或雷达 [原文]（1_核心 §3 支柱 3；3_角色 §1.3"而非雷达"）。
- 不做强引导（1_核心 反面清单）[原文]。
- 不出现"无代价的辨认手段"（2_世界观 禁区）：通灵视必须停在"有没有"，一旦给出"是谁"就越界 [原文 + 推断]。
- 检验问题（支柱 1）：这一个场景是否让玩家多知道一点"谁是谁"？——通灵视只给"这里有东西"，"谁是谁"留给镜。
- 检验问题（支柱 3）：玩家做完这个动作，获得了什么信息？——至少要能答"这里有 / 没有东西"。

## 9·待定与开放问题

1. **生效条件两处原文不一致**：3_角色 §1.3 写"雨，夜晚，需要镜面，灯火昏暗"；story A4 写"雨、夜、灯火昏暗"，没有"镜面"。"需要镜面"是四个条件之一（任一满足即可）、还是必要条件（必须借镜面 / 水面看）、还是笔误？
2. **镜界层归属不清**：story §1.3 把 S9 标为"镜界"，A4 又把通灵视生效条件写在镜界层同一场。镜界层是通灵视的视图、还是镜的窥探（09）？本文按"通灵视视图"解读，待策划定。
3. 条件是"任一满足"还是"须同时满足"？（雨夜昏暗全要，还是其一即可）
4. story §4.2 说序 P3 照何素"看不真"要在 B5 镜照镜时解释——这个"看不真"是镜的结果还是通灵视的结果？本文按镜的结果（归 02）处理。
5. 误判是否要做成机制（R7），还是纯叙事。
6. 主动 / 自动开启、时长、范围（R11、R12）。
7. 先天能力却在 P7 "发放"：P7 之前主角是否已经有通灵视的表现（叙事上已有、系统上未开）？
