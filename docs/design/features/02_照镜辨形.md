## 1·一句话

举镜照向一个对象，镜回答"它是什么"——这是本作的核心辨认动作，也是攻击与收押的前提。

## 2·玩家看到什么

| 输入 | 反馈 | 玩家心理 |
| --- | --- | --- |
| 举镜照物 / 照人 | 镜里正常显形 | "我照见的，和我以为的，是同一个吗？"（1_核心 §5） |
| 举镜照非人之物 | 模糊轮廓（"第四种结果"）或真形 | 同上 |
| 举镜自照 | 镜中只有背后的屋子，没有人；照镜版立绘"反光里没有人" | "镜中一片空白，那么我到底是谁？"（1_核心 §5） |
| 错误用法（照镜背 / 照水面 / 照远处） | 失败，无结果 | "要照对地方、照对方法。" |
| 每次照镜 | 镜缘能看到律条刻痕 | — |

## 3·规则

- R1 一切冲突建立在"能否辨认"上 [原文]（1_核心 §3 支柱 1）。
- R2 攻击手段建立在辨认之上，大略放弃正面战斗 [原文]（1_核心 §3 支柱 1）。C7"引龙照己"——让对方照见自己而停手——是辨认作为攻击手段的一例 [推断]（story C7；该关卡本身原文标"待设计"）。
- R3 收押前提 = 辨认成功 ＋ 对方妖力被削弱；不设血条 [原文]（1_核心 §3 支柱 1）。辨认成功的判定标准 [待定]。
- R4 镜能照见"另一层"的真形 [原文]（2_世界观 铁律 2）。
- R5 镜是判据，只回答问题，回答的是"这是什么" [原文]（2_世界观 §4；3_角色 §0）。
- R6 照镜结果至少四种：照物正常、照人正常、照自己空白、模糊轮廓（第四种结果）[原文]（story P2、P3）。照见清晰真形算第五种还是"模糊轮廓"的完成态 [待定]。
- R7 照见的是一面镜子本身时，镜照镜递归，主角进入镜中世界 [原文]（story B5）。详见 [09_镜中窥探](09_镜中窥探.md)。
- R8 执镜者照不见自己的真形，举镜自照只有空白 [原文]（2_世界观 铁律 5；1_核心 §5；story P2）。序章 P2 可以拒绝自照 [原文]（story P2 分支）。
- R9 存在失败用法：照镜背、照水面、照远处 [原文]（story A2，窦叟处可试）。与 P6 等"照井水"的冲突见第 9 节 Q2。
- R10 辨认必须结合场景内信息 [原文]（2_世界观 禁区）。即只凭照镜不足以辨认，需配合调查所得 [推断]；两者如何组合判定 [待定]。
- R11 辨认要付出镜的耐久；每用一次裂痕风险累积 [原文]（2_世界观 禁区、铁律 2；3_角色 §1.5）。每次消耗多少、"风险"是概率还是确定 [待定]；与"裂纹只在被击溃时产生"的冲突见 [03](03_镜之耐久与镜碎.md) 第 9 节。
- R12 裂痕越多，能照见的越少，潜行时可见范围减少 [原文]（1_核心 §5 失败段）。即照镜的作用范围与潜行可见范围是同一个量 [推断]。
- R13 人做出决定之后，镜不再回答 [原文]（2_世界观 §4；3_角色 §0）。对已由玩家作出判决的对象再照，镜不给答案 [推断]；具体表现 [待定]。
- R14 每段剧情的辨认结果要记录，结局选择依赖它；第三结局要求完成所有鉴定 [原文]（1_核心 §3 支柱 1、§4 硬规则）。"鉴定"与"辨形"是同一动作 [推断]。
- R15 每次照镜都能在镜缘看到律条刻痕 [原文]（2_世界观 §5A）。镜背刻痕随章末新增一行（D9–D10，第三行是玩家自己写的判断）[原文]（story D9、D10）。
- R16 照另一面镜时，镜中背景反映玩家本章的收押记录 [原文]（story D1）。
- R17 扣押敬元颖作为助手后"更容易看破伪装" [原文]（story D2）。以何种形式降低辨认难度 [待定]。

## 8·设计约束与检验问题

- 放弃普通正面战斗、数值成长（支柱 1"放弃了"）：照镜不能有等级、强化 [原文 + 推断]。
- 不出现"无代价的辨认手段"（2_世界观 禁区）[原文]。
- 不做强引导（反面清单）：照镜的目标不应被系统高亮指定 [推断]。
- 不做道德评判：镜只回答"这是什么"，不回答"该怎么办" [原文 + 推断]（3_角色 §0）。
- 检验问题（支柱 1）：这一次照镜，是否让玩家多知道一点"谁是谁"？答不出就砍。

## 9·待定与开放问题

1. **"镜的三条"是哪三条**：story §3.1 P2 分支写"三条规则立完：照物正常／照人正常／照自己空白"；story A7 又说"镜的三条规则词条（含'它只给你看它已经知道的'）"，后者不在前三条里。§1.4 L1 只写"镜的三条"。是同一组吗？
2. **"照水面"是失败用法还是正确用法**：story A2 窦叟列"照水面"为失败用法；但 P6、A5、A10 都是"举镜照井水"并得到结果，B5 照水进入镜中世界。区别是否在于"用水面当镜"与"举镜照向水面"？
3. **照见耗耐久 vs 裂纹只由被击溃产生**：2_世界观 禁区、3_角色 §1.5 说辨认耗耐久；1_核心 §5 只说被击溃时裂纹 +1。见 03 第 9 节。
4. 铁律 2"耐久与次数"是一个量还是两个量？
5. 辨认"成功"的判定：照一下即成功，还是需要与场景信息吻合？
6. 照何素得"模糊轮廓"（P3），story §4.2 说 B5 解释——解释内容原文未写。
7. 失败用法是否消耗耐久。
8. R13 "决定之后不再回答"在玩法上如何体现。
