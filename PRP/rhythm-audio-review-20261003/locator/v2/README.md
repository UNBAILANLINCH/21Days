# 试听微调界面（原 locator 的有界 UX 改进）

入口：**http://127.0.0.1:8767**。双击本目录 `launch.cmd`，看到 READY 后打开该地址，并保持服务窗口打开。可从任意 cwd 启动；需已有 Node，不安装依赖，不注册后台服务，仅 loopback。端口被占用会报错，不停止其他进程。

本轮只新增 `locator/v2/`，原 `locator` 源码与 8766 服务保留，不刷新、关闭或重启用户旧 tab/服务。v2 复用旧版只读 SO 解析和严格 v1 候选校验，不改 Runtime、正式谱面、Unity、共享文档、其他研究候选或 Git index。

## 安全切换，先保护旧页面

**旧 tab 未保存的修改不在新 tab 中，不能据截图声称已读取/迁移。请先保留旧 tab。**

若已下载旧候选 JSON：在新版“导入草稿/旧候选”选择该文件，导入前核对来源 hash，未保存候选替换前提示确认。导入后先点“保存本地草稿”，看到“已保存”再确认四项或其他改动是否完整。

若旧页导出被空审核依据阻挡：无需伪填审核。复制旧页底部**完整差异文字**，以及顶部**原谱/音频的两个完整 SHA-256**；在新版“安全迁移旧页面未保存的修改”展开后粘贴，点“恢复粘贴的差异”。它按 ID、原值、Δ、两个来源 hash 校验，再恢复候选。核对差异后保存本地草稿并下载 JSON。此入口不含用户四个时间的预设值，也不会自动读取旧页。

确认新版草稿 JSON 与旧页差异吻合后，再决定是否关闭旧 tab；工具不会替用户执行这一步。

## 最短使用路径

1. 选择 noteID，顶部固定编辑区清楚显示 ID / lane / 按键 / A 原值 / B 候选 / Δ；表格只在自身滚动区高亮，不把整页跳到表格。
2. 点“定位此音符”只定位；点“循环试听此音符”才播放。可调整前/后秒数。A/B 在同一区间比较同一音频与各自音符 click，不因选择音符自动发声。
3. 用 ±10/±25ms 或数字输入后“应用输入”微调；`[`/`]` 为 ±10ms，Shift 加至 ±25ms，Ctrl+Z / Ctrl+Shift+Z 撤销/重做。输入框、textarea、select、IME 中不触发编辑快捷键。最多保留100步内存历史，刷新不保留撤销历史；导入前后的声部/依据随历史恢复。
4. 时间轴支持放大、缩小、左右移动窗口、全片段及单音符局部定位。B 模式拖动橙色音符，松开合法性检查；冲突或越界拒绝更新。
5. 吸附默认关闭，开关本身不移动音符；开启后只对之后数字输入/拖动按手动 BPM / 原点 / 每拍1、2、4、8细分取最近网格。±ms 小步始终不吸附。103 BPM 与原点0都是未校准参考，不能当作实测，也不能证明贴拍。
6. 直接“保存本地草稿”，声部/审核依据可空。按钮旁显示已保存的时间与差异数。再用“下载草稿 JSON”获得单文件备份；不强制下载两文件。严格审核候选出口另折叠保留，仍要求声部及非空依据，导出旧 v1 `unapproved-candidate` 格式，仍不批准或应用谱面。

## 草稿与保护

草稿格式 `21days-rhythm-draft` / version1 / `unreviewed-draft`。保存或回读保持完整 chart、来源路径/原谱与音频 SHA-256、原 MP3 时间域、差异及真实审核字段。空审核字段原样保留，独立校验不借用伪造声部/理由绕过审核候选校验。只允许合法时间调整；其他谱面字段、ID 顺序、lane、类型与时长不能修改。导入兼容旧 `21days-rhythm-review` version1 候选。

本地存储按两个来源 hash 分键，且依浏览器、配置文件和端口 origin 隔离。显式点击保存，不自动把未保存内容变成“已保存”。刷新发现同来源草稿时，先选择恢复或从原谱开始；从原谱开始使用新副本，保留旧记录。草稿超过30天/版本未知/来源不符时保留而拒绝恢复；新编辑不会覆盖过期主草稿。不同 tab 同时保存用 Web Locks 串行校验旧记录；发现其他页修改时选择恢复其草稿或把当前另存副本，不静默覆盖。不支持该浏览器锁时给出下载 JSON 的替代入口。

保存不是云端同步，也不会写项目文件；清理浏览器数据会失去本地草稿。下载按钮表示已发起浏览器下载，仍需确认下载完成；它不冒充本地保存。未保存候选/审核信息/待应用时间输入在离页时触发浏览器提示。时间输入尚未应用会阻止保存/下载，避免悄悄保存旧值。

原曲秒 = `16 + (timeMs + chartOffsetMs)/1000`。新界面的 click 合成为与音频相同采样率的 AudioBuffer，在同一 AudioContext 时间、80ms余量预约并循环，减少 JS 定时器短循环迟到。画面仍是 rAF；失焦/隐藏暂停。输出设备、浏览器重采样、MP3 与 Unity PCM 解码原点差异未经物理回环验证，历史11ms不自动应用。
