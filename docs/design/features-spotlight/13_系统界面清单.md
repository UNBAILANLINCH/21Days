## 1·一句话

UI 表列了 27 块界面：系统外壳（标题、主菜单、设置、加载）、探索 HUD（边缘箭头、交互提示、高亮、头顶标记、快捷栏、Toast）、对话与过场（对话框、选项、字幕条、章节卡、转场）、调查三件（卷宗、文书翻阅、推理）、地图、背包与道具、战斗与结算（BOSS 血条、章节完成、结算）。其中 BOSS 血条「与音游界面叠加」和带 COMBO 的结算界面，与主页「不另开音游界面」的改动对不上。

## 2·玩家看到什么

按一局游戏的顺序 [推断]（每块界面的内容是 [原文]，见 3.1 表）：
- 开机：标题界面（Logo + 开始 / 继续 / 设置 / 退出）→ 主菜单（继续游戏、读取存档、设置、退出）→ 加载界面（进度条 + 背景插画 / 提示文案）。
- 进场：章节名标题卡（如「入镜」）；人间与镜中妖界之间切换时黑幕加「镜中」之类的过渡文字。
- 探索：屏幕边缘箭头指向可进入的场景 / 楼梯；靠近 NPC 或物体弹出「对话 / 调查 / 拾取」提示，可交互物高亮；NPC 头顶气泡（可对话）或感叹号（有任务）；底部快捷栏放关键道具；右上角浮字提示获得物品、新线索、章节更新。
- 对话：对话框、2–4 个选项按钮（悬停高亮）；过场时底部黑边字幕条。
- 调查：线索 / 卷宗面板、可翻页带竖排文字的文书、连线推理面板；俯视缩略图看位置。
- 背包：物品格子 + 「关键道具 / 材料 / 文书」分类，选中看详情弹窗。
- 战斗：屏幕顶部 BOSS 名称与血条；结束后结算界面（分数、最大 COMBO、评价 S/A/B/C、再来一次）；章节完成提示。
