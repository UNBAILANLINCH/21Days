## 转写说明

- docx、xlsx、内嵌表格、画板都转成 md，原文字不改（含错别字与不统一的写法）。
- 06、07 两份是「图片排版型」Excel：正文全在文本框里、单元格没有文字。转写按原表的行列顺序取出文本框文字、把嵌入图片还原到原位置，文字一字未改（含多余空格、半角逗号、重复段落）。07 的 2026-10-16 版例外：「四、数值相关」「五、道具相关」两节的数值表是真的单元格（含合并单元格），照原样转成 md 表格，合并格用 `<br>` 断行。
- 🔴 表示原文红字（见 03）。
- 表格单元格底色 2026-10-14 起已导出（04 的「底色」列）；「白色的可以不做」按 #ffffff 或无填充判定，这一口径未经策划确认。
- 图片在 `images/`。
- 原人工转写对应的飞书附件（docx / xlsx）未入库，以飞书为准；之后新增并同步的策划附件见 `auto-sync/`。06、07 的原件不在飞书里，入库在 `source/`。
