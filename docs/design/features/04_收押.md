| 术语 | 本系列的意思 |
| --- | --- |
| 收押 | 一个**动作**：以镜的权柄把妖封进主角的镜里。收押完成的那一刻，妖即进入「扣押」状态。 |
| 扣押 | 一种**状态**：妖在镜中被关着。对妖的族属而言，这就是「被扣押」，要记账（见 [07](07_两界之账.md)）。 |
| 收押即扣押 | 收押不是扣押之外的另一种结果；story D2「收进自己的镜里 → 扣押」按此读。 |
| 放归 / 捞出 | 遭遇当场**不收押**，直接放回人间；不进镜、不入账。 |
| 归还 | 对**已扣押**的妖事后改判，放它离镜 / 离皮；销账。 |
| 去处裁定 | 决定一个存在最后落在哪（扣押 / 放归 / 归还 / 驱逐 / 轮回）的判断本身，写在 [05](05_归还与扣押.md)。 |

## 1·一句话

辨认出一只妖、并把它的妖力削弱之后，用镜的权柄把它关进镜里；关住它就等于替它下了一次判决，这笔账会被它的族属记住。

## 3·规则

- **R1** 收押有两个前提，缺一不可：辨认成功、对方妖力被削弱。[原文]（1_核心 §3 支柱1）
- **R2** 不设置血条；「妖力被削弱」不是数值归零，而是一个由情境达成的状态。[原文]前半（1_核心 §3 支柱1）；后半 [推断]
- **R3** 「辨认成功」指用镜照见其真形（见 [02](02_照镜辨形.md)）；只凭通灵视「看见影子」不算。[推断]（依据 3_角色 §1.3「看见不等于确认」）
- **R4** 收押用的是镜本身的权柄，不是执镜者的力量；因此它是「镜中世界不可干涉」的两个例外之一，可对镜界里的存在生效。[原文]（2_世界观 铁律 2；3_角色 §0、§1.5）
- **R5** 收押是一次选择，不是遭遇战的强制结局；与之对立的选项是放归 / 捞出。[原文]（3_角色 §2.4「收押／放归」；story D2）
- **R6** 收押只是关住，不送入轮回、不抹记忆；送入轮回是终章的另一套机制（见 [12](12_断其去处.md)）。[推断]（依据 2_世界观 禁区「转生必须依靠摆渡人的古镜」与 3_角色 §1.5 门 3「终章」）
- **R7** 收押即扣押：每收押一只妖，其族属记下一笔账，不会自行消失；第一章四幕 D5 账簿结算时逐条列出。[原文]（2_世界观 铁律 4；3_角色 §1.5；story D2、D5）。「收押即扣押」本身 [推断]
- **R8** 被收押的妖，其附身过的动物 / 人的面皮可制成傩面具（见 [06](06_画皮傩演.md)）。[原文]（2_世界观 §2 门 2；story §4.3「面具」）
- **R9** 收押是否消耗镜的耐久 / 次数。[待定]（2_世界观 铁律 2 只说「镜有耐久与次数」，未说哪些动作消耗）
- **R10** 以「借体化形」附身人间的妖更容易被收押。[原文]（2_世界观 §2 门 1 代价）。「更容易」在玩法上怎么体现 [待定]
- **R11** 镜会记住收押过的东西：之后照某些镜面时，镜中背景是被收押者。[原文]（story D1）
- **R12** 被扣押者可成为助手，带来被动效果（敬元颖：更容易看破伪装），同时带来叙事代价（受害者之灵的嚎哭）。[原文]（story D2）。是否每只被收押的妖都有助手效果 [待定]
- **R13** 收押时不给「对 / 错」「重要选择」的系统提示。[推断]（依据 1_核心 反面清单「不做道德评判」「不做强引导」与 story A3 对关键选择「无音效、无高亮」的处理）

- **支柱**：支柱 1「辨认，确认，与选择」——收押以辨认为前提 [原文]。
- **铁律**：铁律 2（镜的权柄例外）、铁律 4（记账）[原文]。
- **首次出现**：第一章「第一次收押」[原文]（3_角色 §1.8）。第一章里可能的两次：一幕地图支线 boss（C5，可选）与四幕敬元颖（D2 核心选择）[原文]；哪一次算「第一次」[待定]。
- **解锁时机**：第一章 [原文]（3_角色 §1.5）；在第一章哪一场教学 [待定]。
- **主题投影**：story §1.4 L4「我收了她就是替她判了」——收押不是「抓怪」，是判决 [原文]。何素的恐惧是「被识破和收押」[原文]（3_角色 §4.2），意味着这个能力终会指向主角身边的人 [推断]。

## 8·设计约束与检验问题

- 不设血条、不做数值成长：削弱不能退化成「打空血条」（支柱 1「放弃了」）。
- 不做道德评判、不做强引导：收押与放归都不能被标成正解（反面清单）。
- 不出现「人对妖的单方面碾压」：收押必须有门槛与代价（世界观禁区）。
- 不出现随意转生：收押不得顺带送妖投胎（世界观禁区）。
- **检验问题**（支柱 1）：这一次收押，是否让玩家多知道一点「谁是谁」？答不出就砍。

## 9·待定与开放问题

1. **术语统一（[推断]，待策划拍板）**：1_核心 §5 把「收押妖灵」与「归还／扣押」列成两行；story D2 把「收进自己的镜里」直接等同于「扣押」，与「捞出放回人间」对立。本系列口径：收押 = 封入镜的动作，完成即进入扣押状态；归还 = 对已扣押者的事后改判；放归 / 捞出 = 当场不收押。两行动作的区别落在「关进去」与「之后放不放」。
2. **敬元颖的收押前提**：D2 没写对她做过「削弱」。可读为 B5「镜照镜」= 辨认、C8 放掉龙 = 解除役使即削弱 [推断]，也可能 D2 是剧情选择、不走收押判定 [待定]。
3. **第一次收押是否可跳过**：3_角色 §1.8 写第一章「第一次收押」，像是必经；story C5「若一幕做支线收押过地图怪物」是可选支线，D2 又允许捞出——如果玩家两次都不收押，第一章就没有收押。是否允许？[待定]
4. **面具来源与敬元颖**：story §4.3 写 D2 收押的立即后果含「面具」；门 2 说面具用「附身动物／人之面皮」制作，而敬元颖是「妖灵与镜子的融合」，没有附身面皮。她的面具从哪来？[待定]
5. **门的归属**：2_世界观 §2 把收押写进门 2「画皮傩演」；3_角色 §1.5 把收押单列为「镜的权柄（铁律 2 例外）」，门 2 只含制面具。收押算不算门 2 的一部分、要不要吃「门二乱自我」的反噬？[待定]
