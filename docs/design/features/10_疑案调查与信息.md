## 1·一句话

玩家靠走、看、问、照拿到信息，把信息拼成判断再往前推进；游戏不告诉他下一步去哪、哪个选择重要。

## 2·玩家看到什么

| 输入 | 反馈 |
| --- | --- |
| 在场景里翻找可交互物（P1 ≥6 件，4 信息 / 2 氛围） | 一段描述；有的是事实，有的只是氛围 [原文]（story §二 P1） |
| 找 NPC 对话（A2 六人各一条） | 一条情报；对话次数够了，下一时段（A3）才开放 [原文]（story §二 A2、A3） |
| 在满足条件的时刻用通灵视看场景 | 「影子多了一层」这类轮廓提示，不给身份 [原文]（story §二 A4；3_角色 §1.3） |
| 打开纸上备忘 / 镜中档案 | 已记下的日期、备忘、规则词条、历史碎片 [原文]（story §二 A7、A8）；界面形态 [待定] |
| 在关键处做选择 | 选项与普通对话选项外观一样，不提示分量 [原文]（story §二 A3） |

1_核心 §5 表没有「调查」这一行，本节不引心理列。

## 3·规则

- **R1** 每个玩家动作的回报首先是信息；设计任何交互时要能回答「玩家得到了什么信息」，答不出就重写奖励 [原文]（1_核心 §3 支柱3 解释与检验问题）
- **R2** 不做全知型任务指引；推进靠玩家自己根据信息判断 [原文]（1_核心 §3 支柱3「放弃了」）
- **R3** 不做强引导、不做开放世界 [原文]（1_核心 §3 反面清单）。调查空间是有边界的场景集合（story §1.3 共 S1–S10），不是自由地图 [推断]
- **R4** 全篇三桩疑案：第一章、第二章、第三章各一桩，序章与终章不是疑案 [原文]（3_角色 §1.8）。第一章疑案 = 镜精井案，本章内讲完 [原文]（story §1.1）
- **R5** 信息分四层：L1 规则、L2 事实、L3 主题、L4 自我；每一幕在四层上各有投放，见下表 [原文]（story §1.4）
- **R6** 玩家可查看的信息载体有两个：「纸上备忘」与「镜中档案」，在序章 P7 发放 [原文]（story §二 P7）。纸上备忘对应主角随身那张「记着日期和一些简单备忘的纸」 [推断]（3_角色 §1.1 与 story P7 同名物）
- **R7** 镜中档案全章 8 条，一幕 A7 解锁 3 条（三条规则词条、汉时穿井、被涂掉的「贞观……坠」）；它是镜界里的界面场景 S8 [原文]（story §二 A7、§1.3）。其余 5 条在哪解锁 [待定]
- **R8** 纸上备忘的初始文本受 `note_1_kept` 影响；哥哥痕迹 4 处（A1/A2/A4/A5）全找到时，备忘里出现玩家自注「这套东西，只有一个人会摆。」，不写名字 [原文]（story §3.2、§二 A8）
- **R9** 西市 NPC 情报网：A2 六名 NPC 各给一条情报，含一条可试的「失败用法」教学（窦叟：照镜背 / 照水面 / 照远处） [原文]（story §二 A2）
- **R10** 时段推进由调查量解锁：A3「掌灯」需完成 A2 的 3 次对话；A4「宵禁后」需街鼓响过 [原文]（story §二 A3、A4）。「3 次对话」是指任意 3 名 NPC 还是累计 3 次 [待定]
- **R11** 关键选择不加任何提示：无音效、无高亮、无「重要选择」标记 [原文]（story §二 A3）。该纪律是否推广到全篇所有抉择 [待定]
- **R12** 信息在汇流点合成可行动的判断：一幕 A11 三条线索（井 / 父亲 / 哥哥）汇到井口；二幕 B10 四处信息（前科 / 失和 / 时间窗 / 水道）合成可动手的窗口 [原文]（story §3.3）。汇流由剧情自动完成，还是需要玩家在界面里主动拼合 [待定]
- **R13** 调查足不足直接改变后续难度：C4 备物四件是玩家在 A、B 幕里捡到的，不是系统发的；查得越足 C 幕越省力（`prep_level`） [原文]（story §二 C4、A9）
- **R14** 通灵视是调查工具：用于环境叙事、找线索、分辨「这里有没有东西」，但看见不等于确认 [原文]（3_角色 §1.3、§1.5）。细则见 [01_通灵视](01_通灵视.md)
- **R15** NPC 给信息的写法：可以只说真话但挑选、排序，可以教而不教全，可以藏起一条关键信息 [原文]（3_角色 §2.4，崔昭行为表）。这套写法只约束崔昭，还是作为全作 NPC 的信息给法范式 [推断：作为范式参考，不强制]
- **R16** 每章结束要让玩家产生一个指定疑问（见第 6 节表） [原文]（1_核心 §4）
- **R17** 真相揭示的章节受时间轴「玩家是否知道」一列约束：父亲三年前出走玩家知道；一年前父亲之死第三章才揭示；十六年前的事只作背景 [原文]（2_世界观 §3）
- **R18** 本章埋设分「本章回收」7 条与「只埋不收」10 条；只埋不收的信息允许玩家在本章看不懂 [原文]（story §4.1、§4.2）
- **R19** 漏看信息不阻断主线：玩家不去西坊时崔昭出现推动（A4），痕迹计数可停在 0–4 [原文]（story §二 A4、§3.2）；推广为「可选信息只改难度和台词，不锁主线」 [推断]
- **R20** 通过对话向 NPC 出示信息会改变后续可查度：A2 向陈十六出示笔记 → `chen_trust`，B14 告诉谁 → `told_anyone`，共同决定 C2 旧档来源 [原文]（story §3.2、§二 C2 分支树）

## 8·设计约束与检验问题

- 不做强引导；不做开放世界 [原文]（1_核心 §3 反面清单）
- 放弃全知型任务指引 [原文]（支柱3）
- 世界观禁区：不出现「无代价的辨认手段」，辨认必须结合场景内信息 [原文]（2_世界观 §1 禁区）——调查拿到的信息是辨认的前提，不能替代辨认
- 检验问题：玩家做完这个动作，获得了什么信息？答不出，就重写奖励。（支柱3）
- 辅助检验：这一句台词、这一个场景，是否让玩家多知道一点「谁是谁」？（支柱1）
