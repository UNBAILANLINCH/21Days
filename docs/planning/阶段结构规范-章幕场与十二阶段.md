## 0·一句话结论

**旧版的「章 → 幕 → 场」三级术语在《聚光灯》与工程里都没有对应物：聚光灯只有一级「阶段」，Narrative 阶段机只有 `Story → Stage` 两层扁平图。**

- 内容层的权威术语是**阶段**（序章 + 阶段一至十二），共 13 段；「章 / 幕 / 场」不再作为结构术语使用。
- 唯一需要保留「章」这个字的场合是 UI 文案（章节标题卡、章节完成提示），聚光灯原文自己在 UI 行里也用「章节」（`docs/design/features-spotlight/11_剧情流程与章节结构.md:146`），该行已建议改口径、待拍板。
- 「幕 / 场」没有承接物：Narrative 里没有重开单位、没有时段层、没有幕级变量；旧版这两级承载的三件事（重开粒度、时段切片、场内目标序列）分别落到**存档失败重来（未定）**、**Condition + StoryFlags**、**Quest 目标序列**三处，其中第一件仍是缺口。
- 结构规范不进 PRP（`旧G组-新目标映射与遗留资产.md:177`），但**承载它的工程缺口有明确归属**：多场景流转 A4（`docs/roadmap.md:202`）、加载过渡 E4（`docs/roadmap.md:243`）、关卡专属机制 S6（`docs/roadmap.md:283`）。
