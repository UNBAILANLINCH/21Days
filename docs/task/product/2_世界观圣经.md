### 世界观禁区：

1. 不可有“神明”直接干预，若出现会降低故事人物行动必要性。
2. 不出现随意“转生”设定，必须严格遵循规则：必须依靠“摆渡人”的古镜，将妖的记忆封存于镜中，抹除原主记忆，投入轮回。
3. 尽量避免出现现代科学相关设定，调性不符，本作时代为架空现代／架空的长安，借其坊市、宵禁、傩仪、坊墙的文化气质。
4. 不出现”能自由往返两界的普通人”，若人人可渡，摆渡人这个职位与铁律 2 同时失效。
5. 不出现”无代价的辨认手段”，与支柱 1 冲突；辨认必须结合场景内信息，付出镜的耐久。
6. 不出现”人对妖的单方面碾压”——两界的强弱差必须双向（人不能与妖正面对撞，妖也不能取代人活下去），否则铁律 1 与”人妖平衡”同时失效。

## 4·体系本质

世界内怎么称呼它：人称之为“镜”，妖称之为“照”。

本质：镜不是法器，而是判据——它不制造力量，只回答”你是谁、你是什么”。一切能力都建立在这个回答之上。

可否被转移／继承／偷取：镜可继承（祖父→父亲→主角）；面具不可继承（皮认主）；反派想要的是镜，不是面具。

反噬的梯度：能力越深，对”自我”的损耗越大——门一泄妖力，门二乱自我，门三抹记忆。这条梯度就是本作主题在机制上的投影。

## 5·两界秩序

### A律条 · 镜 · 摆渡人

| 项 | 内容 |
| --- | --- |
| 律条 | 两界共认的界限条款，刻在镜背——主角每次照镜都能在镜缘看到刻痕 |
| 镜 | 唯一的执权之器，也是唯一的判据与刑具 |
| 摆渡人 | 唯一被许可往返两界的人；职责是**调解纠纷、执行律条、送妖入轮回** |
| 为什么必须是人 | 妖若执镜，必以妖界之利断人间之事，两界立刻失衡；镜由人铸，规则强行约束 |
| 继承 | 镜认主，但认的是资格而非血脉：祖父执镜→父亲继任→主角。“子承父业”不是自动的，是要被镜承认的 |
| 代价 | 铁律6，违者被镜带走，不入轮回 |
