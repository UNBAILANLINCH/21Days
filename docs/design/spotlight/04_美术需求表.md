## UI

| 名称 | 说明 |
| --- | --- |
| 标题界面 | 游戏Logo + 开始/继续/设置/退出按钮 |
| 主菜单 | 继续游戏、读取存档、设置、退出 |
| 设置界面 | BGM/音效音量、画质、操作按键、字幕开关 |
| 加载界面（Loading） | 加载进度条 + 背景插画/提示文案 |
| 屏幕边缘导航箭头 | 指向可进入场景/楼梯方向的屏幕边缘箭头 |
| 交互提示按钮 | 靠近NPC/物体时弹出“对话/调查/拾取”按键提示 |
| 可交互物体高亮描边 | 调查点、可拾取物的高亮轮廓 |
| NPC头顶标记 | 对话气泡（可对话）/ 感叹号（有任务） |
| 快捷物品栏 | 当前持有关键道具的快捷栏 |
| 对话框 |  |
| 对话选项按钮 | 2-4个选项按钮，支持悬停高亮 |
| 过场字幕条 | 底部黑边字幕条，对白文字 |
| 章节标题卡 | 阶段一~阶段十二的章节名标题卡（如“入镜”“验堤”） |
| 转场黑幕+过渡文字 | 人间↔镜中妖界转场文字（如“镜中”） |
| 线索/卷宗面板 | 已收集线索列表，按章节/人物分类 |
| 账册/文书翻阅界面 | 归业簿、赈粮册、名簿、香火册等可翻页的书页UI（含竖排文字） |
| 线索关联/推理面板 | 把线索卡片连线组合、推出结论的面板 |
| 场景地图/导航缩略图 | 俯视缩略图，标注当前位置与可进入点（对应两张俯视图） |
| 背包界面 | 物品格子 + 分类标签（关键道具/材料/文书） |
| 物品详情弹窗界面 | 选中物品的图标、名称、描述 |
| 通用按钮组 | 可以和主界面开始等用一个 |
| 通用功能图标集 | 设置齿轮、菜单、背包、地图、对话气泡、存档、音量 |
| Toast/弹窗提示 | 获得物品、新线索、章节更新等右上角浮字提示 |
| BOSS血条 | 屏幕顶部BOSS名称+血条（与音游界面叠加） |
| 章节完成提示 | 章节完成、新线索解锁提示 |
| 结算界面 | 分数、最大COMBO、评价（S/A/B/C）、再来一次 |
| 关键道具图标 | 龙牙、福肉、卷轴、名簿、归业簿、赈粮册的图标 |
