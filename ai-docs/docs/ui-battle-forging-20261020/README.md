## 样式依据与近似

项目基准1920×1080、按高度匹配，最低1280×720，宽屏检查2560×1080。沿UIService的安全区和CanvasScaler，无新根Canvas。

截图明确使用思源宋体CN：Boss名字Bold 43px、红色`#D10404`，招式名Heavy 46px、`#206978`，打造Bold 50px、`#195768`。现有授权源为 `Art/Fonts/SourceHanSerifCN/SourceHanSerifCN-Bold.otf` 及相邻OFL；只在本批组件指定对应TMP资产。Heavy缺失，以Bold近似，不宣称同字重。局部字号根据实际控件宽高调整，并设缩小下限和省略，长Boss名保留宽度480；参考字体截图不是完整战斗构图，战斗控件位置沿原布局适配切片尺寸。

其余截图：回合Bold 29px及玩家HP Bold 17px均为`#348A9B`；怒气消耗Heavy 30px、打造台Heavy 50px为`#5C95A1`；Boss状态Bold 28px为`#E2B664`。金属份额标题Heavy 32px `#E7FBFC`，份额数字Heavy 33px白色；技能角标与工件数量为思源黑体Regular 27px `#1E3633`、1px `#00989D`描边。数字复用既有思源黑体Regular TMP与相邻OFL；本批未增加独立描边材质，因此1px描边属于明确近似，不能修改共享字体材质来偷偷影响其它界面。

血条填充放在11px内边距轨道内，比例作用于轨道，防止0值时负宽反向绘制。切片保留透明度，UI纹理使用Single Sprite、无mipmap、无压缩，未改变全局导入器；装饰与文字不参与射线。按钮保留导航与命中区域。
