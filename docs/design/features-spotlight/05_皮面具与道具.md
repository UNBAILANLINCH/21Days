## 1·一句话

皮与面具是身份的载体，钥匙与一次性道具是过关和操纵机关的凭证，材料可以合成新道具；它们大多从击杀或暗杀特定怪物得来，不少要跨阶段带着走，在后面的关口或 BOSS 战才派上用场。

## 2·玩家看到什么

- 杀掉或暗杀一个怪物，地上掉出它的「皮」或「面具」；拿到后背包里多一件，右上角弹「获得物品」。[推断]（掉落见 sp03 各阶段 [原文]；浮字提示见 sp04「UI · Toast/弹窗提示」[原文]）
- 背包按「关键道具 / 材料 / 文书」三个标签分页，点开一件看图标、名称、描述；常用的关键道具放在快捷物品栏。[原文]（sp04「UI」）
- 有的东西用一次就没了：普通皮进一家店铺、量尺调一次水位、通往酒肆的钥匙、蜃师面具。[原文]（sp03）
- 有的东西拿着就生效：空白皮让玩家在弥勒教地区自由通行，查勘使面具让半龙侍放行，泾龙面具 / 泾龙丹让钱塘君战直接跳过一阶段。[原文]（sp03）
- 两样东西能合成一样新的：水痕 + 湿皮 → 钥匙，泾龙丹 + 空白皮 → 泾龙面具。[原文]（sp03）在哪合、怎么合，原文没写。[待定]
- 阶段3 拿到的「牙」，到阶段六、阶段九的 BOSS 面前才发挥作用。[原文]（sp03）

## 3·规则

### 3.1 获得方式

- **R1** 剥脸：主角通过剥脸获得面具。[原文]（sp00「讨论记录」）
- **R2** 击杀 / 暗杀掉落：绝大多数皮和面具写的是击杀或暗杀特定怪物后获得，逐件见 3.5 道具总表。[原文]（sp03 各阶段）有的写「暗杀」有的写「击杀」，两种杀法掉的东西是否不同，原文没写。[待定]
- **R3** 序章：暗杀小怪「获得面具」，即「能力面具1」。[原文]（sp05「序章流程」）
- **R4** 身份能力产出（sp02 套）：附身金银匠，用多出来的金属份额打造金钥匙，打造完成提交后带出道具金钥匙；衣肆里找到正确的顾客后取走道具「衣服」。[原文]（sp02「场景三 金银行 · 二、场景玩法」「场景二 衣肆 · 二、场景玩法」）
- **R5** 条件拾取：拾骨人持有篮子时不可击杀，行动时会把篮子放在地上；玩家拾取篮子会触发追逐，摆脱后在篮子中获得「牙」；此后击杀拾骨人可以获得骨牙面具。[原文]（sp03「阶段3 · B 特定怪物 · 3 拾骨人」）「此后」读作「先拿到牙，拾骨人才可被击杀并掉骨牙面具」。[推断]
- **R6** 场所获取：药行可以获取暗杀使用的药和特殊效果道具。[原文]（sp03「阶段1 · B 特定怪物 · 6 药行」）是买、偷还是暗杀药师获得，原文没写。[待定]
- **R7** 合成：水痕 + 收服户绝民的湿皮 → 进入废弃官署的钥匙；泾龙丹 + 空白皮 → 泾龙面具。[原文]（sp03「阶段3 · A 底层怪物」「阶段九个 · C 关键怪物 · 泾龙鬼」）
- **R8** 合成在哪里进行、用什么界面、原料合成后是否消失，原文没写。[待定] 参与合成的湿皮限定为「收服户绝民的」那张 [原文]（sp03「阶段3 · A 底层怪物」），说明湿皮有「收服前 / 收服后」两种状态。[推断]

### 3.2 次数：一次性、持有型、生效中

- **R9** 原文写明一次性的有四件：普通皮（使用后可以进入坊市店铺，不可复用）、量尺（一次性道具，调节水位一次）、通往酒肆的一次性钥匙、蜃师面具（一次性道具，挡一次揭露或看破一个房间的幻象一次）。[原文]（sp03「阶段1 · A 底层怪物」「阶段3 · B 特定怪物 · 2 录事」「阶段1 · C 关键怪物 · 4 官署」「阶段九个 · B 特殊怪物 · 蜃师」）
- **R10** 写了「生效中」的有一件：执事皮。[原文]（sp03「阶段六 · B 特定怪物 · 灰衣收入」）说明它有生效时段。[推断] 时长多少、怎么开始生效，原文没写。[待定]
- **R11** 写成「拥有 / 持有即可」的：空白皮（拥有这个可在弥勒教任意地区自由通行）、查勘使面具（如持有也可自由通行）、泾龙面具与泾龙丹（如持有可以直接跳过一阶段）。[原文]（sp03「阶段六 · C 关键怪物 · 分福身」「阶段九个 · B 特殊怪物 · 半龙侍」「阶段九个 · C 关键怪物 · 钱塘君」）这几件读作持有型，不因使用而消失。[推断]
- **R12** 其余道具的次数原文没写，见总表「次数」列。[待定]

### 3.3 跨阶段携带

- **R13** 「牙」：阶段3 获得，可以削弱阶段六 BOSS 食教者；阶段九的泾龙鬼也可用「牙」削弱；阶段九的半龙侍也掉「牙」。[原文]（sp03「阶段六 · C 关键怪物 · 食教者」「阶段九个 · C 关键怪物 · 泾龙鬼」「阶段九个 · B 特殊怪物 · 半龙侍」）削弱食教者后牙是否还在、能否留到阶段九再用，原文没写。[待定]
- **R14** 查勘使面具：阶段3 获得，「在后续阶段有作用」；阶段九持有它可在半龙侍处自由通行。[原文]（sp03「阶段3 · C 关键怪物 · 2 查勘使」「阶段九个 · B 特殊怪物 · 半龙侍」）
- **R15** 市令：阶段一击杀市令，到阶段3 殁吏处「可直接通过此身份通行」。[原文]（sp03「阶段3 · B 特定怪物 · 1 殁吏」）这条带过来的是道具还是身份，见 Q9。
- **R16** 空白皮：阶段六获得，是「通往第九阶段龙府的钥匙之一」；阶段九在籍中吏处可用空白皮通行。[原文]（sp03「阶段六 · C 关键怪物 · 分福身」「阶段九个 · B 特殊怪物 · 籍中吏」）「钥匙之一」说明进龙府还有别的钥匙。[推断] 其余是哪些，原文没写。[待定]
- **R17** 泾龙丹可直接跳过最终 BOSS 战斗一阶段，「在后续也有作用」。[原文]（sp03「阶段九个 · C 关键怪物 · 泾龙鬼」）「后续」指什么，原文没写。[待定]
- **R18** 由 R13–R17 看：背包要跨阶段保留，道具不能按阶段清空，并且要进存档。[推断]
- **R19** 坊市（sp03 套）：集齐三个 BOSS（乐官、行首、知金银行都料）的面具后可开启坊正战斗，击杀坊正获得通往酒肆的一次性钥匙。[原文]（sp03「阶段1 · C 关键怪物」）三件面具怎么拿到，原文只写了「获得」。[待定]

## 6·与叙事的咬合

- 「皮」「面具」两个道具类别直接对应主题「傩戏+画皮+志怪」[原文]（sp00「讨论记录」）里的傩戏面具与画皮。[推断]
- 「牙」能削弱食教者与泾龙鬼 [原文]（sp03），剧情上民间祠堂供奉「龙牙」[原文]（sp01「阶段五：实地勘察」），信众信仰「被吃的龙」[原文]（sp01「阶段七：弥勒教」）：牙是被吃之龙留下的东西，所以能克制吃它的人。[推断]

- 「福事」（玩法）与「福肉」（剧情、UI）读音形近，剧情里一个人「成为」了粮 [原文]（sp01「阶段七：弥勒教」）；执事皮能把特定信众直接转化为福事 [原文]（sp03）。两者是否同一物待定（Q7）。[推断]
- 「泾龙丹」掉自泾龙鬼 [原文]（sp03），剧情里钱塘龙君「吃了泾川龙第二子」[原文]（sp01「阶段九：找龙」）；持泾龙丹可在钱塘君战跳过一阶段，是受害者的遗物对加害者起作用。[推断]
- 阶段六 BOSS 食教者「外表为多个“皮”缝合而成」[原文]（sp03），与玩家收集各种皮形成对照。[推断]

## 8·设计约束与检验问题

**约束**（从原文推出 [推断]）

- 道具要跨阶段保留并进存档（R18），否则「阶段3 的牙削弱阶段六 BOSS」无法成立。
- 一次性与持有型要在界面上一眼区分，玩家才不会舍不得用或用错。
- 很多道具只在后面的阶段才有用（牙、查勘使面具、空白皮、泾龙丹），要在获得时就给出暗示，否则玩家不知道为什么要冒险去拿。
- 同一个关口常有多种过法（殁吏三种、籍中吏两种、钱塘君战两种跳阶段道具），道具是「换一种过法」而不是唯一钥匙。
- sp04 的三个背包标签装不下「消耗品」与「一物两用」的道具（R27），分类方案要先定。

**检验问题**

- 玩家拿到一件道具时，能否从描述里知道它是一次性的还是持有型的？
- 每件「用途原文未写」的皮与面具（信众皮、水族皮、骨牙面具、半龙侍面具、能力面具1）是否真有用处？没有用处的是否该删？
- 错过关键跨阶段道具（例如阶段3 没拿到牙）时，后面的 BOSS 是否仍可通过？
- 背包里同时有十几种皮、面具时，快捷物品栏放哪些？
