## 1·一句话

调查是把散在两界的证词、文书和实地物证收集起来、彼此比对、推出结论：阶段一靠附身不同的人去对话（客栈透露别的场景的线索、衣肆从多名顾客里找出唯一来取衣服的人），之后各阶段靠名簿、归业簿、赈粮册、香火册这些文书的「对不上」一路追到弥勒教与钱塘龙君。UI 表为此要了三块界面：线索 / 卷宗面板、可翻页带竖排文字的文书界面、连线推理面板。

## 2·玩家看到什么

- 靠近 NPC 或物体，弹出「对话 / 调查 / 拾取」按键提示；调查点、可拾取物有高亮轮廓 [原文]（sp04「UI」第 6、7 行）。
- 附身成某个人，跟其他人对话交流信息；同一个场景换不同身份，能听到不同的话 [原文]（sp02 学徒、杂役「只能跟其他人对话交流信息」）/ [推断]（换身份听到不同的话）。
- 衣肆里依次附身几名顾客，和裁衣匠、其他顾客对话，判断「我是不是来取衣服的」；认准后向裁衣匠报上身份、说要取衣服，取走道具「衣服」[原文]（sp02「场景二 衣肆」）。
- 拿到新线索，右上角浮字提示；章节完成时有「新线索解锁」提示 [原文]（sp04「UI」第 23、25 行）。
- 打开线索 / 卷宗面板，按章节或人物查看已收集的线索；打开文书，翻页阅读竖排文字的归业簿、赈粮册、名簿、香火册；在推理面板里把线索卡片连线组合，推出结论 [原文]（sp04「UI」第 15–17 行）。

### 3.3 规则

- R1　对话是阶段一的线索来源：学徒、杂役这类普通身份「只能跟其他人对话交流信息」；酒肆的对话选择会改变结果（选对能灌怪物的酒，反之被灌）[原文]（sp02「场景一」「场景三」「场景五」）。说它是阶段一「最主要」的来源，是本文按 sp02 各场景玩法归纳的 [推断]。醉酒机制本身归 [07](07_关卡专属机制.md)。
- R2　附身与线索：阶段一「通过换皮获得线索」；讨论记录写剥脸后「继承身份/物品/记忆进行解谜」[原文]（sp01「阶段一：入镜」；sp00「讨论记录」）。由此看，附身是取得线索的前提，换了谁的身份就能用谁的人脉和记忆去问 / 去想 [推断]；「记忆」怎么呈现给玩家（自动给线索、解锁对话选项、还是可翻看的回忆）[待定]（Q1）。
- R3　客栈是线索枢纽：场景内多名角色专门用来对话，对话中透露其他场景的线索 [原文]（sp02「场景四 客栈」）。客栈本身没有附身目标与机制描述 [原文]（同上），它的作用就是给别的场景指路 [推断]。
- R4　市令：sp03 那套阶段一设计里的巡逻怪物，可交互获得坊市内怪物信息和线索，暗杀则可得通行任何区域的道具、难度很高 [原文]（sp03「阶段1 坊市」）。「交互拿情报」与「暗杀拿道具」看起来是二选一 [推断]，是否互斥 [待定]（Q3）。
- R5　衣肆推理：裁衣匠在柜台后，玩家无法绕到背后附身他 [原文]；场内有多名顾客，玩家可以分别附身，附身后能和裁衣匠及其他顾客对话、分析自己是不是要取衣服，也可以向裁衣匠上报身份说要取衣服；这些顾客里只有一个是来取衣服的，找到正确的人取走道具「衣服」[原文]（sp02「场景二 衣肆」）。推理依据（谁说了什么、凭什么判断）原文没写 [待定]；选错人去上报会怎样（暴露？只是拿不到？）原文没写 [待定]（Q2，与 [02](02_身份暴露与怀疑.md) 相关）。sp03 那套设计里衣肆是「顾客 巡逻怪物，3-4个」加 BOSS 行首，没有这段推理 [原文]（sp03「阶段1 坊市」）。
- R6　文书是阶段二以后的主线索，见 3.1 表 [原文]（sp01；sp04）。UI 表点名的四种翻阅文书是归业簿、赈粮册、名簿、香火册 [原文]（sp04「UI」第 16 行）；案件记录、赈灾命官名单、卷轴原文提到但没列入翻阅界面 [原文]（对照 sp01、sp04），是否也做成可翻页文书 [待定]（Q6）。
- R7　文书的价值在「对不上」：名簿 vs 案件记录对不上、手迹出自官府（二）；归业簿空账（三）；赈粮册递减、一名两份、第五年断（四）；香火册空白（五）——阶段七把这些串起来：两个名字不是领了两份，而是一个人「成为」了粮 [原文]（sp01 阶段二至七）。证据链本身是 [原文]，「玩家亲手把这几处连起来」是 [推断]：大纲只写了结论，没写谁推出来的（Q4）。阶段八、十一继续用官府记录与赈粮册追人 [原文]（sp01）。
- R8　实地物证：水位那一年上升三尺（三）；土质异常、民间祠堂供奉「龙牙」、坟地没有尸首、第三年起不再新开坟地（五）；领受「福肉」而无人解释（六）[原文]（sp01）。阶段五整段名为「实地勘察」[原文]，调查点（sp04「UI」第 7 行）主要落在这里 [推断]。
- R9　证人：sp04 主线角色表里多数人的说明就是「提供什么信息」——轮回堂值守核验名簿、泾阳老吏做归业簿、民众讲述当年灾情 / 坟地断新 / 分福仪式由来、镜中乡老告知秘藏与开教者、王录业调取案件记录与命官名单、赵十四告知妻子转生去向 [原文]（sp04「主线角色」）。sp01 阶段五写的是「和乡中老人交谈当年情况」，而 sp04 把讲述当年灾情归给「民众」[原文]，见 Q10。
- R10　三块调查界面：线索 / 卷宗面板（已收集线索列表，按章节 / 人物分类）；账册 / 文书翻阅界面（可翻页的书页 UI，含竖排文字）；线索关联 / 推理面板（把线索卡片连线组合、推出结论）[原文]（sp04「UI」第 15–17 行）。推理面板「推出结论」后结论用来做什么（推进阶段、解锁对话、解锁地点）[待定]（Q4）。
- R11　调查的入口与反馈：交互提示分「对话 / 调查 / 拾取」三类；可交互物有高亮轮廓（调查点、可拾取物）；新线索有右上角浮字，章节完成时有「新线索解锁」提示 [原文]（sp04「UI」第 6、7、23、25 行）。
- R12　文书也是道具：背包分类里有「文书」，关键道具图标包含名簿、归业簿、赈粮册（以及龙牙、福肉、卷轴）[原文]（sp04「UI」第 19、27 行）。同一份文书既进背包、又能翻阅、又能作为线索卡进推理面板 [推断]；香火册在翻阅界面里，却不在关键道具图标里 [原文]（Q7）。道具规则归 [05](05_皮面具与道具.md)。
- R13　战斗关里也有调查：阶段3 要找「地图线索中的“刻度”」交给录事调水位，老吏被击败后给予线索和剧情；阶段九要「地图解谜」找出藏在幻象房里的蜃师，还能透过非特殊镜面看相邻房间 [原文]（sp03「阶段3 泾阳」「阶段九个 龙窟」）。这些机制本体归 [07](07_关卡专属机制.md)。
- R14　sp03 阶段3 的「账簿」不是供阅读的文书，而是记录玩家用过的身份、超量触发追逐的机制 [原文]（sp03「阶段3 泾阳」），归 [02](02_身份暴露与怀疑.md)、[04](04_追逐.md)。它和阶段三剧情里的归业簿同处一个阶段，是否有意呼应 [待定]。
- R15　两界对照是调查手段：阶段二拿妖界的名簿对人间的案件记录 [原文]（sp01「阶段二」）；阶段八在人间官府查到老吏、去妖界追问 [原文]（sp01「阶段八」）。一条线索在一界找到、到另一界验证，是反复出现的调查节奏 [推断]（地点见 [10](10_两界与场景结构.md)）。

## 6·与叙事的咬合

- 文书链就是明线本身：名簿 → 归业簿 → 赈粮册 → 香火册，每一份都「对不上」或「空」，阶段七一次揭开「一个人“成为”了粮」[原文]（sp01）。调查玩法若让玩家亲手比出这些矛盾，叙事高潮就落在玩家自己手里 [推断]。
- 赈粮册两次出场：阶段四揭出「同一个名字领两份粮」，阶段十一妻子的转世「在赈粮册上，出现了两次」[原文]（sp01）——同一份文书把旧案与寻妻接在一起 [推断]。
- 竖排文字的书页 UI（sp04「UI」第 16 行）与唐代官府文书的题材相合 [推断]。
- 结案「不提邪教之事」[原文]（sp01「阶段十二」）：玩家查到的比官方结论多，线索面板里留着的就是「暗」的那一半 [推断]。

## 8·设计约束与检验问题

- 推理要由玩家完成还是剧情直接给？检验：去掉推理面板，大纲是否照样能走完——能走完，推理面板就只是装饰。
- 衣肆推理的信息量：几名顾客、每人说什么、唯一解如何保证不靠试错？要给出完整的「证词 → 排除」表。
- 文书的「对不上」要能被看见：翻阅界面是否需要并排对照两份文书（名簿 vs 案件记录）？竖排文字的可读性与长度要控制。
- 线索按「章节 / 人物」分类：一条线索同时属于多个人物时如何归档？
- 换身份听到不同的话（R2）会让对话内容按身份数成倍增长，要控制每个场景可附身的身份数。
- 战斗关里的地图线索（刻度、地图解谜）与剧情调查共用一套线索面板，还是只在关内生效？
