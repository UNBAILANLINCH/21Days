## 1·一句话

主角撑不住妖的一击，所以不打：靠追逐里的逃脱、躲藏里的不被发现、识破弱点后的一次决定性行动，以及对场景的利用来过关；只有特定精英 / boss 战借面具正面打。

## 3·规则

**总则**

- R1 主角在现实与镜中长安都要潜行行动。[原文]（`1_核心 §1`）
- R2 普通对抗只用四种手段：追逐、躲藏、弱点识破、场景利用。[原文]（`1_核心 §3·反面清单`；`3_角色 §1.1` 列前三种）
- R3 主角不与妖正面对撞；人在妖那一层极脆弱。[原文]（`2_世界观圣经.md 铁律 1`；`1_核心 §3·支柱 1`）
- R4 不设血条，不做数值成长；对抗强弱不来自主角变强。[原文]（`1_核心 §3·支柱 1`；`3_角色 §1.4`）

**胜负条件**

- R5 失败＝主角被正面击溃；一次正面命中即算（“一击溃散”）；镜替他挡下，代价是镜面多一道裂纹。[原文]（`1_核心 §5`；`2_世界观 铁律 1`）
- R6 裂痕不可修复，每多一道，潜行时可见范围减少。[原文]（`1_核心 §5`）裂痕计数与可见范围的定义归 [03](03_镜之耐久与镜碎.md)，本文只引用。
- R7 碎裂三次后重开关卡；失败页只写“镜碎”，不用“读档”字样。[原文]（`1_核心 §5`）
- R8 胜利条件按手段分：追逐＝逃脱到安全点或坚持到时限；躲藏＝在限定时间 / 区域内未被发现；弱点识破＝完成一次针对弱点的行动；场景利用＝触发场景机关达成前三者之一。[推断] 具体判定 [待定]，见 Q1。

**追逐**

- R9 追逐的主要来源是妖族“追讨”：主角扣押越多，追讨压力越大。[原文]（`2_世界观圣经.md 铁律 4`）首个追逐关在第二章（“讨债”）。[原文]（`3_角色 §1.7`；铁律 4 首次出现“第二章开头”）
- R10 压力的具体化（追兵数量、速度、频次随扣押数上升）。[推断] 公式 [待定]
- R11 人间一侧的追查者（宵禁武侯）也构成躲避对象，可借身份道具脱身。[推断]（`story 第一章 P4 / A4`：武侯盘问、见戏班记号不查）

**躲藏**

- R12 光线与天候影响「看见」：通灵视只在雨、夜、镜面、灯火昏暗时生效 [原文]（`3_角色 §1.3`；规则归 [01](01_通灵视.md)）；井下「灯灭即视野归零」[原文]（`story 第一章 B2`）。躲藏关里光线同时影响主角视野与被发现概率，可见范围是双方共同的资源 [推断]。「潜行可见范围」这个量的定义与裂痕缩减规则归 [03](03_镜之耐久与镜碎.md) R6，本文只引用。
- R12a 躲藏被发现后是转入追逐、还是直接判失败。[待定]

**弱点识破**

- R13 弱点识破不是削血：一次识破对应一次决定性结果（第一章：龙在水面看见自己 → 停下）。[原文]（`story 第一章 C7`）
- R14 识破的首要产出是信息，玩家要能说出“我识破了什么”。[原文]（`1_核心 §3·支柱 3`）
- R15 弱点来自该妖的真形与执念，识破手段往往是“让它照见自己”。[推断]（`story 第一章 C7` 龙“不自照”→ 照见自己后停下；B7 龙“在核对炭记”）是否作为通用规则 [待定]
- R16 妖附体化形时妖力外泄、易被察觉，这是**妖被主角察觉**的方向，不是主角被妖察觉。[原文]（`2_世界观圣经.md §2 门 1`）它给弱点识破提供线索来源。[推断]（细则见 [13](13_妖的化形与破绽.md)）

**场景利用**

- R17 场景与物件可降低对抗难度：前期查得越足，后面越省力。[原文]（`story 第一章 C4`）第一章实例：水位随街鼓涨落、须踩节奏（B1）；灯的范围（B2）；四件封龙物（C4 / C8）。[原文]把这些归为“场景利用”[推断]。

**例外：面具正面战**

- R18 只有特定精英 / boss 战允许正面对抗，且必须借画皮面具的妖力，每场只带一张。[原文]（`1_核心 §3·反面清单`；`2_世界观 铁律 1`、`§2 门 2`）细则见 [06](06_画皮傩演.md)。
- R19 面具正面战的胜负条件（没有血条时怎样算打赢）。[待定]

## 8·设计约束与检验问题

- 不做普通正面战斗，不设血条，不做数值成长。（支柱 1）
- 正面战只限特定精英 / boss，且必须戴面具。（反面清单第一条、铁律 1）
- 不做人对妖的单方面碾压；强弱差必须双向。（`2_世界观` 禁区）
- 弱点识破不能是无代价雷达：识破必须结合场景内信息。（`2_世界观` 禁区“不出现无代价的辨认手段”适用 [推断]）
- 不做全知指引：弱点在哪要靠玩家自己查。（支柱 3“放弃了全知型任务指引”）
- 失败文案只写“镜碎”，不写“读档”。（`1_核心 §5`）
- **检验问题（支柱 1）**：这一句台词、这一个场景，是否让玩家多知道一点“谁是谁”？
- **检验问题（支柱 3）**：玩家做完这个动作，获得了什么信息？答不出，就重写奖励。
