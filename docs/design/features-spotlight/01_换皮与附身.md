**统一用法小结** [推断]：

1. **换皮**是总称；**附身**和**使用 / 持有皮、面具**是原文写明的两种做法，二者是否同一机制待定。
2. **皮**、**面具**是两个道具类别，各件道具用原名；两类的功能差别待定。
3. **身份**是被借用的角色；**本体**是没借用任何身份的主角。
4. **伪装**是借来的身份正在生效的状态；**暴露**是这个状态被识破的结果。
5. 「穿皮」原文没有，本系列不用。

## 1·一句话

主角本体很弱，靠「换皮」借别人的身份行事：绕到一个角色背后附身它，或从怪物身上取得皮、面具，继承对方的身份、物品和记忆，拿到这个身份才有的能力和出入权限，用来解谜和通行。

## 2·玩家看到什么

以下按原文拼出玩家体验；画面、操作细节原文都没写。

- 主角本体弱，打不过任何怪物，被打会被击倒、只能慢慢挪动，所以要潜行接近别人、绕到背后。[原文]（sp00「讨论记录」）
- **阶段一（sp02 套）**：先以学徒的身份进戏班，换成都知把巡逻的学徒调开，再换成乐正去解音乐谜题——乐正看到的谜题是正常的，别人看到的是乱的；在衣肆里一个个附身顾客，靠对话推出谁是来取衣服的；在金银行里先附身官证改文书，再附身金银匠打造金钥匙；在酒肆里附身怪物去和别的怪对话、劝酒。[原文]（sp02 各场景）
- **阶段一（sp03 坊市套）**：杀妖民掉普通皮，用一次就能进一家坊市店铺；酒肆要有特定身份才进得去。[原文]（sp03「阶段1」）
- **后续阶段（sp03）**：杀或暗杀特定怪物掉皮、面具，用来过守门怪物（殁吏、籍中吏）、混进巡逻队、在某区域自由通行。[原文]（sp03 阶段3 / 六 / 九）
- 附身信众之后，原本恐怖的分福祠变成一片祥和的景象。[原文]（sp03「阶段六 · 区域设想」，原文为「增加设想」）
- 屏幕上怎样显示「我现在是谁」「这个身份能做什么」：原文没写；sp04 的 UI 表里没有「当前身份」一类的条目。[待定]

## 3·规则

### 3.1 取得身份的途径

- **R1** 剥脸：主角通过剥脸获得面具，并借此继承身份、物品、记忆来解谜。[原文]（sp00「讨论记录」）
- **R2** 阶段一的推进手段叫「换皮」：通过换皮获得线索，五个场景后击败 BOSS1、得到妻子的位置。[原文]（sp01「阶段一：入镜」）这五个场景就是 sp02 的戏班、衣肆、金银行、客栈、酒肆，所以 sp01 的「换皮」指的就是 sp02 的附身玩法。[推断]
- **R3** 附身：sp02 的戏班、衣肆、金银行、酒肆写明玩家可附身场景里的角色，酒肆写的是「附身怪物」；sp03 阶段六写了「附身信众」。[原文]（sp02 各场景；sp03「阶段六 · 区域设想」）客栈只写了「多名角色用来对话」，能不能附身没写。[待定]
- **R4** 同一场景里可以先后附身多个角色，前一个身份做成的事留给后一个身份用：戏班 学徒进门 → 都知调走学徒 → 附身乐正解谜；金银行 附身官证改文书 → 附身金银匠打造；衣肆 分别附身多名顾客。[原文]（sp02「场景一 戏班 · 三、场景玩法」「场景二 衣肆 · 二、场景玩法」「场景三 金银行 · 二、场景玩法」）

## 8·设计约束与检验问题

**约束**（从原文推出 [推断]）

- 本体打不过任何怪物（sp00），所以换皮必须是主要解题手段，每个关卡至少有一步「只有某个身份才能做」。
- 附身条件要让玩家一眼看懂：谁能附身、谁不能（柜台后的裁衣匠），站位本身就是提示。
- 一个场景内的身份要分工：sp02 每个场景都有「普通成员」（学徒、杂役）只管对话，再有一两个带专属能力的身份。
- 身份的能力和限制是成对出现的（乐正能解谜，但在解谜区不能被看见），借身份不能只有好处。

**检验问题**

- 玩家不读说明，能不能看出「我现在是谁、这个身份能做什么、不能做什么」？
- 每个可附身角色是否都有一个不可替代的用途？只会对话的身份（学徒、杂役）除了带路还有没有存在感？
- 附身与暗杀（都要绕背）在操作上怎么区分，玩家会不会想附身却杀了人？
